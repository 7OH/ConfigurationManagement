## 0.3.8.28 — 2026-09-18

Исправления открытых issues (по одному релизу на issue).

### 0.3.8.23 — #250 Двойной клик в колонке «Платформа» по всей её ширине
Выбор версии платформы теперь открывается двойным кликом по любой части колонки «Версия платформы», а не только по надписи (Windows/WPF и Linux/Avalonia).

### 0.3.8.24 — #251 Частичная версия платформы без разрядности в режиме «Все»
Выбор частичной версии («папки» — линии «8.3» или группы «8.3.27») в фильтре «Все/Авто» больше не подставляет разрядность x86; возвращается чистая версия «8.3.27».

### 0.3.8.25 — #253 Автоотметка и индикатор «Логин/пароль» через единый резолвер
Наличие логина/пароля в окне «Определение конфигураций всех баз» определяется через единый `InfobaseAuthResolver` (учёт `EnterpriseAuth`, `ConfiguratorAuth`, базовая авторизация), согласованно с главным списком.

### 0.3.8.26 — #254 Выравнивание элементов в окне определения конфигураций
Содержимое ячеек таблицы центрировано по вертикали (`VerticalContentAlignment=Center`), элементы строк выровнены по одной линии.

### 0.3.8.27 — #255 Производительность списка (ранний выход в ReorderGridColumns)
Убран избыточный сброс `ColumnDefinitions` при материализации каждой строки — меньше нагрузка на раскладку и «рывки» при прокрутке большого списка.

### 0.3.8.28 — #252 Позиция списка стабильнее после сохранения свойств базы
Внутренний `ScrollViewer` дерева кэшируется (сброс при `Unloaded`), что уменьшает «прыжки» списка при пересборке и прокрутке.

### Исполняемые файлы
- Windows x64: `ConfigurationManagement.exe`
- Linux x64: `ConfigurationManagement-linux-x64`

Обе сборки — Windows/WPF и Linux/Avalonia — проходят без ошибок. Issues остаются открытыми.
