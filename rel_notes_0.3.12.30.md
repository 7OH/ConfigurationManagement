# 0.3.12.30

## Добавлено

### issue #375 — «Актуальные релизы»: фильтр «Только в базах»

- В окно «Актуальные релизы» (Alt+F9) добавлена галочка **«Только в базах»**.
- Галочка **включена по умолчанию**: список отслеживаемых конфигураций ограничивается
  теми, что присутствуют в списке информационных баз.
- Конфигурация считается присутствующей в базах:
  - по **явной привязке** — связь ИБ ↔ типовая конфигурация (`UpdateConfigCode`);
  - по **эвристике** — сопоставление имени конфигурации базы (`ConfigurationName`)
    с типовой конфигурацией.
- Переключение галочки пересобирает список на обеих платформах (WPF и Avalonia).

## Тесты

Добавлено 9 тестов (`ActualReleasesBaseFilterTests`): фильтр по привязке и по эвристике,
отсутствие совпадений, пустые списки, несколько баз, устаревшая привязка с переходом на
эвристику, проверка присутствия конфигурации по коду.
