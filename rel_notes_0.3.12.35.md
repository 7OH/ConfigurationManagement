# 0.3.12.35

## Исправлено

### issue #352 — «Цепочки обновлений»: в индикаторе показывалось имя конфигурации

- При скачивании цепочки обновлений в индикаторе фоновых загрузок главного окна
  показывалось название конфигурации («УТ 11»), а не скачиваемый файл.
- Теперь заголовок фоновой записи при старте заменяется именем первого файла цепочки,
  а в цикле скачивания обновляется на имя текущего файла — как при одиночном скачивании
  (для полного файла заголовок уже был корректным).
- Добавлен метод `BackgroundDownloadManager.UpdateTitle(id, title)`: атомарно обновляет
  заголовок активной записи и уведомляет индикатор (`Changed`); неактивные/несуществующие
  записи и пустые заголовки игнорируются.
- Обе платформы: WPF и Avalonia.

## Тесты

Добавлено 3 теста (`BackgroundDownloadManagerTests`): обновление заголовка активной записи
с событием `Changed`, игнорирование неактивных/неизвестных записей, игнорирование пустых
заголовков.

## Проверка

- Полный прогон тестов: 2570/2570 зелёных.
- Ручной чек-лист: запуск скачивания цепочки обновлений («Скачать цепочку») — в индикаторе
  главного окна видно имя текущего файла (меняется по шагам); одиночное скачивание не
  изменилось.
