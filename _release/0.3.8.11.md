# Управление конфигурациями 1С — 0.3.8.11

## Проверка обновлений конфигураций и «Актуальные релизы»

В этой версии добавлены функции №21 и №22 StartManager: проверка обновлений типовых
конфигураций 1С по web-ресурсу обновлений и окно «Актуальные релизы». Реализовано для
**Windows/WPF** и **Linux/Avalonia** на общей чистой .NET-логике.

### Что нового

- **Проверка обновлений для выбранной ИБ (F9)** — окно с текущей и последней версией,
  статусом и адресом каталога релизов; новый релиз подсвечивается, доступна загрузка
  дистрибутива с индикатором прогресса.
- **Окно «Актуальные релизы» (ALT+F9)** — список отслеживаемых типовых конфигураций и
  пакетная проверка с результатами по строкам и загрузкой.
- **Список типовых конфигураций** — предопределённый набор + пользовательские; задаются
  имя, сегмент web-адреса и редакции (`Ред`/`Подред`).
- **Настройка связи ИБ ↔ конфигурация** и кнопка «Определить версию» — чтение имени и
  версии конфигурации из структуры базы (COM на Windows / эвристика и `DESIGNER` на Linux).
- Формирование ссылок обновлений по правилу 1С
  `downloads.1c.ru/ipp/.../Configs/<Конфигурация>/<Ред>/<Подред>/`; ручная корректировка
  адреса через переключатель «Авто/Вручную».
- Хоткеи **F9** / **ALT+F9** настраиваются в настройках приложения.

### Известные ограничения

- Парсинг каталога релизов `downloads.1c.ru` может быть неустойчивым или каталог может быть
  закрыт/перемещён. При невозможности определить точную последнюю версию приложение честно
  сообщает об этом вместо ложного результата; сетевые ошибки не роняют интерфейс.
- Для доступа к части каталогов 1С может требоваться авторизация на сайте 1С.
- Связь ИБ ↔ конфигурация настраивается вручную или автоматически по имени конфигурации
  при определении версии.
