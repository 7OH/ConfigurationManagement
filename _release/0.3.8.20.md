# Управление конфигурациями 1С — 0.3.8.20

## Колонка «Дата изменений» + автосохранение состояния списка

В этой версии реализован **Этап 13** дорожной карты StartManager: колонка «Дата изменений»
файла ИБ (функция №3) и сохранение/восстановление состояния списка — раскрытых групп —
с настраиваемой периодичностью автосохранения (функция №15, дополнение). Реализовано для
**Windows/WPF** и **Linux/Avalonia**.

### Что нового

- **Колонка «Дата изменений» файла ИБ** — настраиваемая колонка списка баз, показывающая
  дату и время последнего изменения файла информационной базы (`LastWriteTime`):
  - время берётся из файловой базы (`1Cv8.1CD`) и приводится из UTC к локальному,
    отображается в формате `dd.MM.yyyy HH:mm`;
  - значение формируется в [`Models/Infobase.cs`](../Configuration%20Management/Models/Infobase.cs)
    (`FileLastWriteTimeUtc` / `LastModifiedDisplay`);
  - колонка участвует в перечне колонок наравне с остальными: **видимость**, **ширина**
    и **порядок** настраиваются в **Настройки → Отображение → Колонки**;
  - у не файловых баз и до чтения значения показываются «—» и «…».
- **Автосохранение состояния списка (раскрытые группы)**:
  - свёрнутые группы записываются в профиль (`CollapsedGroups`, `infobases.json`)
    и применяются при загрузке — раскрытие групп восстанавливается между сеансами;
  - при работе состояние помечается изменённым и периодически автосохраняется таймером;
  - периодичность настраиваемая (`ListStateAutoSaveIntervalSeconds`, по умолчанию 10 секунд),
    включение/выключение — `AutoSaveListState`; автосохранение срабатывает только при наличии
    изменений, не создавая лишней нагрузки на диск.
- **Единая логика для обеих платформ** — реализация выполнена для **Windows/WPF**
  ([`Views/MainWindow.Columns.cs`](../Configuration%20Management/Views/MainWindow.Columns.cs),
  общий `MainViewModel`) и **Linux/Avalonia**
  ([`Views/MainWindow.Avalonia.Columns.cs`](../Configuration%20Management/Views/MainWindow.Avalonia.Columns.cs),
  `MainViewModel.Avalonia.cs`).
- Локализация ru/en заголовка колонки «Дата изменений» (`Column.Modified`) присутствует в
  [`Localization/Languages/ru.json`](../Configuration%20Management/Localization/Languages/ru.json) и `en.json`.
- **Тесты** — новые регрессионные тесты
  [`ConfigurationManagement.Tests/Etap13ListStateTests.cs`](../ConfigurationManagement.Tests/Etap13ListStateTests.cs)
  покрывают отображение «Даты изменений» (файловая/нефайловая база, неразрешённое значение,
  формат даты) и значения настроек автосохранения по умолчанию.

### Как использовать

1. Для показа «Даты изменений» открыть **Настройки → Отображение → Колонки** и включить
   колонку «Дата изменений» (можно задать порядок и ширину). Она отображается у файловых баз.
2. Автосохранение состояния списка включается настройкой `AutoSaveListState` (по умолчанию
   включено); периодичность — `ListStateAutoSaveIntervalSeconds` (по умолчанию 10 секунд).
   Раскрытие групп запоминается автоматически и восстанавливается при следующем запуске.

### Известные ограничения

- Дата изменений читается для файловых баз; для клиент-серверных и веб-баз колонка показывает «—».
- Автосохранение состояния выполняется таймером только при изменении раскрытия групп;
  параметры периодичности задаются через файл настроек профиля.
