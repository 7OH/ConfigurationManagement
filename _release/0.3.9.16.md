# 0.3.9.16 — 2026-09-20

## Что нового

### Исправления

- **Окно «Список типовых конфигураций» (#265)** — улучшена работа с окном:
  - закрытие окна по клавише `Esc`;
  - вертикальное выравнивание текста в колонках по центру;
  - подсветка только нечётных строк (при наведении мышью и при навигации курсором);
  - окно стало по-настоящему модальным.
  Реализовано в обеих версиях: **Windows/WPF** и **Linux/Avalonia**.

- **Окно «Актуальные релизы» (#264)** — те же четыре улучшения, что и для окна
  «Список типовых конфигураций»:
  - закрытие окна по `Esc`;
  - вертикальное центрирование текста;
  - подсветка только нечётных строк;
  - настоящая модальность окна.
  Обе платформы **WPF** и **Avalonia/Linux**.

- **ESC и открытая подсказка (#261)** — надёжное детерминированное закрытие открытой
  подсказки (ToolTip) по первому `ESC`; повторный `ESC` сворачивает окно в трей.
  Реализован механизм «закрытие + подавление повторного открытия» (veto), который
  предотвращает возврат подсказки при наведённом курсоре и устраняет рецидив,
  который прежние фиксы (0.3.9.4 / 0.3.9.8 / 0.3.9.12 / 0.3.9.13 / 0.3.9.15)
  не устранили. Обе платформы **WPF** и **Avalonia/Linux**.

## Версия

  `<FileVersion>`, `<InformationalVersion>`) в `Configuration Management.csproj`.
