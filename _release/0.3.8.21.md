# Управление конфигурациями 1С — 0.3.8.21

## Исправление краха Windows/WPF при запуске

В этой версии устранён критический сбой запуска WPF-версии для Windows, внесённый в 0.3.8.10 вместе с оптимизацией размера single-file сборок.

### Симптом

При старте Windows-версии выбрасывалось исключение:

```
System.Windows.Markup.XamlParseException: Set property 'System.Windows.Window.Title' threw an exception.
 ---> System.InvalidOperationException: Cannot find non-neutral culture related to 'en-us'.
   at System.Windows.Markup.XmlLanguage.GetSpecificCulture()
   at System.Windows.Data.BindingExpressionBase.GetCulture()
```

Окно не появлялось.

### Причина

В версии 0.3.8.10 была включена **инвариантная глобализация** (`InvariantGlobalization=true`) для уменьшения self-contained single-file сборок на ~5–20 МБ (исключение ICU-данных). На Windows/WPF это ломает резолв специфичной культуры: при активации **любой** привязки с конвертером (в том числе локализованных `{loc:Loc ...}` заголовков) WPF вызывает `XmlLanguage.GetSpecificCulture()`, который не может найти не-нейтральную культуру (`en-us`) при отсутствии ICU-данных и бросает исключение. Так как привязок с конвертерами в интерфейсе много, WPF-приложение не могло запуститься вовсе.

### Решение

`InvariantGlobalization` **отключён**:
- свойство удалено из [`Configuration Management.csproj`](../Configuration%20Management/Configuration%20Management.csproj);
- флаг `-p:InvariantGlobalization=true` убран из скриптов сборки [`build-windows-single-file.ps1`](../Configuration%20Management/build-windows-single-file.ps1), [`build-linux-single-file.ps1`](../Configuration%20Management/build-linux-single-file.ps1) и [`build-linux-single-file.sh`](../Configuration%20Management/build-linux-single-file.sh).

ICU-данные снова включаются в сборку — размер single-file увеличивается, но WPF-интерфейс с привязками работает корректно. На Linux/Avalonia поведение не изменяется.

Дополнительно добавлен защитный нуль-чек в `MainWindow.OnClosing`, чтобы аварийное закрытие окна не приводило к `NullReferenceException`.

## Исполняемые файлы
- **Windows (x64):** `ConfigurationManagement.exe`
- **Linux (x64):** `ConfigurationManagement`

## Сборка обеих платформ
- Windows/WPF и Linux/Avalonia (`-p:ForceLinux=true`) собираются скриптами без ошибок.
