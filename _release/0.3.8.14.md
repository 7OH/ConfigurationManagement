# Управление конфигурациями 1С — 0.3.8.14

## Интеграция с проводником Windows

В этой версии добавлена функция №12 StartManager: интеграция с проводником Windows —
регистрация ассоциации `.1CD` и команд контекстного меню. Реализовано для **Windows/WPF**
на реестре текущего пользователя (`HKCU\Software\Classes\`) без прав администратора.
На **Linux/Avalonia** функция недоступна (реестр/Shell — Windows-специфично): используется
заглушка, пункт настройки показан заблокированным с пояснением.

### Что нового

- **Ассоциация `.1CD`** — двойной щелчок по файлу базы открывает её в приложении;
  значок берётся из исполняемого файла.
- **Контекстное меню проводника** для `.1CD`:
  - **Зарегистрировать в списке баз** — добавляет базу в список приложения;
  - **Запустить 1С:Предприятие** — запускает базу в режиме «1С:Предприятие»;
  - **Запустить Конфигуратор** — запускает базу в режиме «Конфигуратор».
- Команды вызывают исполняемый файл приложения с параметрами
  `--register "<путь>"` / `--launch "<путь>"` / `--designer "<путь>"`;
  обработка выполняется при запуске приложения.
- **Включение через настройки** — Настройки → Базы → Обслуживание → **Интеграция** →
  «Интегрировать с проводником». Выключение удаляет ассоциацию и команды из реестра.

### Известные ограничения

- Функция доступна только на **Windows** (WPF). На Linux пункт настройки заблокирован.
- Ассоциация и команды хранятся в реестре текущего пользователя (`HKCU`) — при переносе
  профиля или запуске от другого пользователя интеграцию нужно включить заново.
- При повторном запуске уже открытого приложения команда выполняется в новом процессе
  (этот экземпляр обрабатывает аргументы до проверки одиночного экземпляра).
