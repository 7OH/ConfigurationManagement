# Управление конфигурациями 1С — 0.3.8.22

## Что исправлено

В этой версии объединены два открытых pull request для Linux-платформы.

### #258 — Подтверждение установки обновлений при ручной проверке

Ручная проверка обновлений больше не подтверждает установку версии без вопроса о согласии. Теперь перед установкой пользователю выводится запрос, и версия устанавливается только после явного согласия.

### #259 — Кнопки в разделе «Базы» настроек для Linux

В разделе «Базы» настроек кнопки приведены к разметке WPF. В результате две возможности, ранее недоступные в Linux/Avalonia-версии, стали доступны.

## Исполняемые файлы
- **Windows (x64):** `ConfigurationManagement.exe`
- **Linux (x64):** `ConfigurationManagement`

## Сборка обеих платформ
- Windows/WPF и Linux/Avalonia (`-p:ForceLinux=true`) собираются скриптами без ошибок.
