# Управление конфигурациями 1С — 0.3.8.17

## Автозапуск при старте ОС + копия экрана

В этой версии реализован **Этап 8** дорожной карты StartManager: автозапуск приложения
при начале работы операционной системы (функция №31) и сохранение копии экрана по
сочетанию клавиш (функция №30). Реализовано для **Windows/WPF** и **Linux/Avalonia**.

### Что нового

- **Автозапуск при старте ОС** — переключатель «Запускать приложение при старте ОС»
  в **Настройки → Базы → Обслуживание**.
  - На **Windows** путь к приложению записывается в ключ реестра
    `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` — раздел текущего пользователя,
    права администратора не требуются.
  - На **Linux** создаётся файл автозапуска десктоп-окружения
    `~/.config/autostart/configuration-management.desktop`.
- **Копия экрана по хоткею** — настраиваемое сочетание (по умолчанию **Ctrl+F12**,
  вкладка «Клавиши») сохраняет снимок в PNG.
  - На **Windows** захватывается весь виртуальный рабочий стол (все мониторы) через
    `Graphics.CopyFromScreen`.
  - На **Linux/Avalonia** — снимок главного окна приложения через рендер визуального
    дерева.
  - Каталог сохранения задаётся в **Настройки → Базы → Обслуживание**; если поле пусто —
    используется каталог «Изображения». Имя файла — `screenshot_ГГГГММДД_ЧЧММСС.png`.

### Как использовать

- **Автозапуск:** Настройки → Базы → Обслуживание → «Запускать приложение при старте
  ОС». Изменение применяется сразу; при выключении запись автозапуска удаляется.
- **Копия экрана:** Настройки → Клавиши → «Копия экрана» — задать сочетание
  (по умолчанию Ctrl+F12); Настройки → Базы → Обслуживание — указать каталог сохранения.
  Нажать сочетание — снимок будет сохранён, путь к файлу показывается в сообщении.

### Известные ограничения

- На Linux копия экрана — снимок главного окна приложения (без внешних зависимостей
  системный захват всего экрана не реализован); на Windows захватывается вся область
  рабочего стола.
- Горячая клавиша копии экрана работает, когда активно окно приложения (по общей схеме
  горячих клавиш проекта).
