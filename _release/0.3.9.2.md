## Что нового

### Настройки логина/пароля для авторизации на сайте 1С (HTTP Basic Auth)
При проверке обновлений конфигураций 1С заголовок `Authorization` теперь может передаваться на
web-ресурс обновлений. Это позволяет обращаться к защищённым каталогам `downloads.1c.ru`, где для
доступа к дистрибутивам требуется логин/пароль.

Заголовок формируется на основе настроек `UpdatesLogin` / `UpdatesPassword`
(`OneCUpdatesService.AddBasicAuth`) и передаётся:
- при проверке обновлений выбранной ИБ (**F9**);
- в окне «Актуальные релизы» (**ALT+F9**);
- при скачивании дистрибутива.

Настройка выполняется в окне **Настройки** (обе платформы: **Windows/WPF** и **Linux/Avalonia**),
локализация ru/en — ключи `Updates.AuthGroupTitle`, `Updates.Login`, `Updates.Password`, `Updates.AuthHint`.

## Исполняемые файлы

- **Windows x64** — `dist/win-x64/ConfigurationManagement.exe`
- **Linux x64** — `dist/linux-x64/ConfigurationManagement`

## Сборка обеих платформ

- Windows: `dotnet build "Configuration Management/Configuration Management.csproj"`
- Linux: `dotnet build "Configuration Management/Configuration Management.csproj" -p:ForceLinux=true`

Обе сборки проходят без ошибок.
