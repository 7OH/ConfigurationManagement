# 0.3.9.0 — 2026-09-18

## Что исправлено

### #260 — Закрытие окна «Определение конфигураций всех баз» без двойного вопроса
В Linux/Avalonia-версии обработчик закрытия не отменял закрытие при отказе («Нет»), из-за чего
вопрос подтверждения показывался повторно. Теперь при необработанных отмеченных строках и ответе
«Нет» закрытие отменяется (`e.Cancel = true`) — как в Windows/WPF-версии.

### #254 — Выравнивание элементов строки в окне «Определение конфигураций всех баз»
Текст текстовых колонок `DataGrid` рендерился через сгенерированный `TextBlock`, растянутый на всю
высоту ячейки, поэтому стоял выше галочки/индикатора/кнопки, несмотря на
`VerticalContentAlignment=Center`. Добавлен `ElementStyle` с `VerticalAlignment=Center` для всех
текстовых колонок — элементы каждой строки выровнены по одной линии.

### #252 — Список баз больше не «скачет» после сохранения свойств базы
Позиция прокрутки запоминается до пересборки дерева (новое событие `TreeRebuilding`) и
восстанавливается после неё в `RevealAndSelectAfterRebuild` (паттерн из Linux/Avalonia-версии).
После правки свойств список остаётся на прежнем месте.

### #255 — Уменьшены «рывки» списка при прокрутке, стабилизирована полоса
Три независимые правки в WPF: не пересчитывать ширину заголовка на изменение `ExtentWidth`;
не перезапускать стабилизацию выравнивания заголовка на каждой реализованной строке; отложенные
прокрутки к выбранной строке захватывают данные, а не переиспользуемый контейнер, и склеиваются
по флагу (при автоповторе клавиши «вниз» список перестал «прыгать» и продолжаться двигаться
после отпускания).

### #251 — Приоритет платформы для «папки» в режиме Авто
При открытии окна выбора версии с частичной версией («8.3» / «8.3.27») выделение остаётся на самой
папке, а не переходит на максимальную полную сборку; переключение фильтра разрядности больше не
смещает выделение с папки. Частичная версия выбирается в чистом виде без подстановки разрядности
x86. Симметрично на Windows/WPF и Linux/Avalonia.

### #250 — Двойной клик по всей колонке «Платформа»
Колонку платформы при координатной проверке определяют динамически по элементу с
`Tag="PlatformVersion"` (его фактической позиции после переупорядочивания колонок), а не по
фиксированному индексу, который расходился с реальным положением колонки. Двойной клик по пустой
области колонки «Платформа» снова открывает выбор версии, а не запускает базу.

## Исполняемые файлы

- **Windows x64** — `dist/win-x64/ConfigurationManagement.exe`
- **Linux x64** — `dist/linux-x64/ConfigurationManagement`

## Сборка обеих платформ

- Windows: `dotnet build "Configuration Management/Configuration Management.csproj"`
- Linux: `dotnet build "Configuration Management/Configuration Management.csproj" -p:ForceLinux=true`

Обе сборки проходят без ошибок.
