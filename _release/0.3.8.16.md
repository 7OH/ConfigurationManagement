# Управление конфигурациями 1С — 0.3.8.16

## Внешняя обработка при запуске + действие по двойному щелчку

В этой версии реализован **Этап 7** дорожной карты StartManager: внешняя обработка,
запускаемая при открытии информационной базы (функция №25), и настраиваемое действие
по двойному щелчку на базе (функция №28). Реализовано для **Windows/WPF** и **Linux/Avalonia**.

### Что нового

- **Внешняя обработка при запуске ИБ** — в свойствах базы появилось поле «Внешняя
  обработка» (.epf/.erf). При открытии базы в режиме «1С:Предприятие» выбранная
  обработка запускается автоматически: путь передаётся ключом `/Execute "путь"`,
  а необязательные данные обработки — ключом `/C "данные"` в строке запуска.
  Настройки задаются во вкладке «Режим запуска» окна свойств базы.
- **Действие по двойному щелчку** — настраиваемое действие при двойном клике на базе:
  «Запустить 1С:Предприятие», «Запустить Конфигуратор» или «Ничего».
  - **Глобально** — в **Настройки → Базы** (по умолчанию — запуск «1С:Предприятие»).
  - **Индивидуально для ИБ** — в свойствах базы; значение «По умолчанию» использует
    глобальную настройку, явный выбор переопределяет её для конкретной базы.
- Локализация ru/en, единый чистый кроссплатформенный сервис без UI-зависимостей.

### Как использовать

- **Внешняя обработка:** свойства базы → вкладка «Режим запуска» → поле «Внешняя
  обработка при запуске» → выбрать `.epf/.erf` (кнопка «Обзор…») → при необходимости
  заполнить «Данные внешней обработки (/C)». При следующем запуске базы в режиме
  «1С:Предприятие» обработка откроется автоматически.
- **Действие по двойному щелчку:** Настройки → Базы → «Действие по двойному щелчку
  на базе» для глобальной настройки; свойства конкретной базы → вкладка «Режим
  запуска» → «Действие по двойному щелчку» для индивидуального переопределения.

### Известные ограничения

- Внешняя обработка запускается только в режиме **«1С:Предприятие»**; в «Конфигураторе»
  ключи `/Execute`/`/C` неприменимы.
- Путь к обработке, содержащий символ `"` или управляющие символы, не подставляется
  в командную строку (безопасность CLI).
