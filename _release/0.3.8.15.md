# Управление конфигурациями 1С — 0.3.8.15

## chdbfl.exe и консоль администрирования серверов 1С

В этой версии реализован **Этап 6** дорожной карты StartManager: быстрый запуск `chdbfl`
для проверки целостности файловой ИБ (функция №29) и запуск консоли администрирования
серверов 1С для клиент-серверных баз. Реализовано для **Windows/WPF** и **Linux/Avalonia**.

### Что нового

- **Проверка целостности файловой ИБ (chdbfl, Ctrl+Alt+Q)** — команда «Проверить
  целостность (chdbfl)» в контекстном меню **файловой** базы. Исполняемый файл
  (`chdbfl.exe` на Windows / `chdbfl` на Linux) ищется в каталоге установленной платформы
  1С рядом с `1cv8`/`1cv8.exe`; проверка выполняется над файлом базы `<путь>\1Cv8.1CD`.
- **Консоль администрирования серверов 1С (Ctrl+Alt+S)** — команда «Консоль
  администрирования серверов» в контекстном меню **клиент-серверной** базы. Подходящий
  инструмент определяется по платформе: на Windows предпочтительно оснастка MMC
  `1CV8Servers.msc`, иначе кросс-платформенный командный клиент `rac`.
- **Настраиваемые хоткеи** — обе команды вынесены во вкладку «Клавиши» настроек
  (по умолчанию `Ctrl+Alt+Q` и `Ctrl+Alt+S`) на обеих платформах.
- Локализация ru/en, единый чистый кроссплатформенный сервис без UI-зависимостей.

### Как использовать

- Выберите **файловую** базу → контекстное меню → **Проверить целостность (chdbfl)**.
- Выберите **клиент-серверную** базу → контекстное меню → **Консоль администрирования
  серверов**.

### Известные ограничения

- `chdbfl` доступен только для **файловых** баз; команда скрыта для остальных типов.
- Консоль администрирования серверов доступна только для **клиент-серверных** баз.
- При отсутствии установленной платформы 1С (каталога `bin` нужной разрядности) команды
  завершаются с предупреждением.
