# 0.3.8.23 — 2026-09-18

## Что исправлено

### #250 — Двойной клик в колонке «Платформа» срабатывает по всей её ширине

Раньше выбор версии платформы открывался только при двойном клике точно по надписи
в колонке «Платформа»; клик по пустой области этой колонки запускал базу.
Теперь двойной клик по любой части колонки «Версия платформы» открывает окно выбора версии.

- **Windows/WPF** — обработчик двойного клика определяет колонку под курсором по координате
  внутри сетки строки и открывает пикер, если это колонка платформы.
- **Linux/Avalonia** — ячейка платформы растянута на всю ширину колонки (текст прижат влево),
  поэтому двойной клик по пустой области тоже открывает выбор версии.

## Исполняемые файлы

- **Windows x64** — `dist/win-x64/ConfigurationManagement.exe`
- **Linux x64** — `dist/linux-x64/ConfigurationManagement`

## Сборка обеих платформ

- Windows: `dotnet build "Configuration Management/Configuration Management.csproj"`
- Linux: `dotnet build "Configuration Management/Configuration Management.csproj" -p:ForceLinux=true`

Обе сборки проходят без ошибок.
