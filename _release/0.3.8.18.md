# Управление конфигурациями 1С — 0.3.8.18

## Режимы функциональности + конфиг 1CLaunch.cfg + портативный режим

В этой версии реализован **Этап 10** дорожной карты StartManager: режимы функциональности
(Пользователь / Специалист / Разработчик) с ограничением системного меню (функция №1),
параметры запуска по умолчанию из файла `1CLaunch.cfg` и портативный режим / установка
на сменный носитель (перенос настроек). Реализовано для **Windows/WPF** и **Linux/Avalonia**.

### Что нового

- **Режимы функциональности: Пользователь / Специалист / Разработчик** — выбираются в
  **Настройки → Настройки → «Режим функциональности»**. Значение хранится в настройках
  канонической строкой и не зависит от языка интерфейса.
- **Ограничение системного меню для режима «Пользователь»** — в контекстном меню
  информационной базы остаются только запуск Предприятия/Конфигуратора, избранное и
  закрепление; системные операции (редактирование, удаление, выгрузки `.dt`/`.cf`,
  резервирование, блокировки, администрирование и др.) скрываются.
- **Параметры запуска из `1CLaunch.cfg`** — ключи `configpath` (asp/usp/sp), `configdir`,
  `appmode`, `selectmodeoff`. Файл ищется в портативном каталоге, каталоге exe и системном
  каталоге данных. **Приоритет аргументов командной строки приложения над файлом**.
  Параметры подставляются лаунчером как значения по умолчанию, если те же ключи уже не
  заданы параметрами самой базы.
- **Портативный режим / установка на сменный носитель** — детект запуска со сменного
  носителя: наличие `portable.dat` рядом с исполняемым файлом либо переменная окружения
  `CONFIG_MANAGEMENT_PORTABLE=1`. В портативном режиме каталог данных настроек
  (`ConfigurationManagement-Data`) располагается рядом с приложением, поэтому переносится
  вместе с носителем; при первом запуске данные копируются из системного каталога профиля.

### Как использовать

- **Режим функциональности:** Настройки → Настройки → «Режим функциональности» →
  Пользователь / Специалист / Разработчик → «Сохранить». В режиме «Пользователь» сразу
  применяется ограничение системного меню.
- **Параметры по умолчанию из `1CLaunch.cfg`:** положить файл рядом с исполняемым файлом
  (или в портативный/системный каталог данных), например:
  ```ini
  configpath=usp
  configdir=C:\Конфигурации
  appmode=2
  selectmodeoff=1
  ```
  Параметры применяются при запуске 1С, если не переопределены командной строкой.
- **Портативный режим:** создать файл `portable.dat` в каталоге исполняемого файла (либо
  запустить с env-флагом `CONFIG_MANAGEMENT_PORTABLE=1`). При первом запуске существующие
  данные копируются в портативный каталог и далее хранятся рядом с приложением.

### Известные ограничения

- Ограничение системного меню действует на контекстное меню базы в главном окне; полноценная
  разграничительная политика отдельных команд между режимами «Специалист»/«Разработчик»
  оставлена на последующие этапы (сейчас оба режима дают полный доступ).
- Ключи `configpath`/`configdir`/`appmode` передаются в строку запуска 1С как значения по
  умолчанию; их реальное поведение зависит от конкретной конфигурации 1С, использующей эти
  параметры.
