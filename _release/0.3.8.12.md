# Управление конфигурациями 1С — 0.3.8.12

## Сценарии резервирования и восстановление

В этой версии добавлены функции №16 и №18 StartManager: сценарии резервирования
и «Список выгрузок» с восстановлением данных. Реализовано для **Windows/WPF** и
**Linux/Avalonia** на общей чистой .NET-логике.

### Что нового

- **Сценарии резервирования (SHIFT+CTRL+F5)** — модель сценария: наименование,
  шаблон имени файла (`{Base}` `{Timestamp}` `{Date}` `{Time}`), до трёх каталогов
  назначения, формат DT/CF/ZIP/RAR, префикс базы и учётные данные. Сценарии хранятся
  отдельными JSON-файлами в каталоге данных профиля (`backups/scenarios`),
  количество не ограничено.
- **Выполнение сценария для выбранной ИБ** — пакетная выгрузка `.dt`/`.cf` через
  конфигуратор (`RunDesignerBatch`), ожидание завершения выгрузки, при формате ZIP/RAR
  результат пакуется и копируется во все каталоги назначения. Для RAR требуется внешний
  архиватор (winrar/rar) — его путь задаётся в настройках или берётся из PATH.
- **«Список выгрузок» (SHIFT+CTRL+F7)** — обзор созданных файлов `.dt/.cf/.zip/.rar`
  по каталогам сценариев и настраиваемым каталогам, сортировка по дате, «Открыть папку».
- **Восстановление данных** — новая операция `RestoreIB` (`/RestoreIB"path"`) в пакетном
  режиме конфигуратора, без интерактивного окна 1С:Предприятия. Для `.zip`/`.rar` файл
  сначала распаковывается во временный каталог и берётся первый `.dt`/`.cf`.
- Учётные данные сценария: по умолчанию используется авторизация базы (`ConfiguratorAuth`);
  при необходимости задаются явные логин/пароль.
- Хоткеи **SHIFT+CTRL+F5** / **SHIFT+CTRL+F7** настраиваются в настройках приложения;
  пункты добавлены в контекстное меню информационной базы.

### Известные ограничения

- Восстановление выполняется для файлов выгрузки `.dt`; для `.cf` доступен только
  просмотр в списке выгрузок (загрузка конфигурации — отдельная операция конфигуратора).
- Формат **RAR** требует установленного внешнего архиватора (winrar/rar); если он не
  найден, приложение честно сообщает об этом и предлагает сменить формат на ZIP.
- Каталоги назначения должны быть доступны на запись; недоступный каталог пропускается
  с предупреждением в журнале.
- Автозапуск сценариев по расписанию и блокировки сеансов не входят в объём этапа.
