# 0.3.9.4 — 2026-09-18

## Исправления

- **Пояснения к режиму функциональности (#263)** — в окне «Настройки» у каждого режима
  («Пользователь»/«Специалист»/«Разработчик») теперь показывается своё описание, а не «сырой» ключ
  локализации. Добавлены недостающие ключи `Settings.General.FunctionalModeHint`,
  `FunctionalMode.SpecialistHint`, `FunctionalMode.DeveloperHint` в русский и английский словари.
- **ESC закрывает открытую подсказку (#261)** — при открытой ToolTip в главном окне первый ESC
  закрывает подсказку, и только второй сворачивает/прячет окно в трей (WPF и Avalonia).
- **Окно «Определение конфигураций всех баз» (#260)** — при досрочном закрытии вопрос подтверждения
  показывается ровно один раз: добавлен guard-флаг против реентерабельного Closing (WPF и Avalonia).
- **Кнопка «Актуальные релизы» на общей панели (#262)** — глобальная команда вынесена из контекстного
  меню базы на верхнюю панель команд; добавлено подменю «Утилиты» для сбора общих команд (WPF и Avalonia).
- **Горизонтальный скролл списка при запуске (#255)** — убран необоснованный горизонтальный скролл:
  горизонталь дерева держится на нуле (WPF и Avalonia).
- **Перескок вниз при листании по папке (#255)** — шаг прокрутки ограничен размером вьюпорта,
  чтобы строка группы не «уводила» список на высоту всех её детей (WPF и Avalonia).
- **Позиция после правки свойств базы (#252)** — если группа базы не изменилась, список восстанавливает
  прежний offset вместо BringIntoView и больше не сдвигается (WPF).

## Версия

- Версия поднята до `0.3.9.4` во всех четырёх полях (`<Version>`, `<AssemblyVersion>`,
  `<FileVersion>`, `<InformationalVersion>`) в `Configuration Management.csproj`.

## Сборка обеих платформ

- Windows: `dotnet build "Configuration Management/Configuration Management.csproj"`
- Linux: `dotnet build "Configuration Management/Configuration Management.csproj" -p:ForceLinux=true`
