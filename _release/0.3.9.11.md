# 0.3.9.11 — 2026-09-19

## Исправления

- **Fix #263 — Пояснена разница режимов «Специалист» / «Разработчик»**
  (`065ca10`, `9c739ef`). В поле выбора режима запуска добавлены пояснения различий между
  режимами Специалист и Разработчик; использован вложенный класс `FunctionalModeOption`
  вместо локального `record` (для совместимости Avalonia).
- **Fix #262 — Убран дублирующий пункт контекстного меню базы**
  (`58ccb4b`). Из контекстного меню базы удалён дублирующий пункт «Список типовых
  конфигураций», который появлялся повторно.
- **Fix #261 — ESC закрывает открытый ToolTip перед скрытием окна**
  (`a096092`). При нажатии ESC теперь сначала закрывается открытая всплывающая подсказка,
  и только затем окно.
- **Fix #260 — Вопрос подтверждения при закрытии «Определения конфигураций» — один раз**
  (`d85e006`). Диалог подтверждения закрытия окна «Определение конфигураций» больше не
  показывается повторно (перенесён из `Closing` в отложенный вызов; WPF + Avalonia).
- **Fix #255 — Устранён перескок вниз при листании клавишами по папке**
  (`b4f6fa7`). При пролистывании элементов папки клавишами список больше не перескакивает
  вниз — прокрутка выполняется по заголовку группы (WPF + Avalonia).
- **Fix #252 — Восстановление позиции прокрутки после отмены редактирования свойств базы**
  (`e1d3a3c`). Позиция прокрутки списка восстанавливается после отмены редактирования
  свойств базы.

## Версия

  `<FileVersion>`, `<InformationalVersion>`) в `Configuration Management.csproj`.
