# 0.3.8.26 — 2026-09-18

## Что исправлено

### #254 — Выравнивание элементов в окне «Определение конфигураций всех баз»

В WPF-версии содержимое ячеек таблицы не центрировалось по вертикали: галочки и кнопка
свойств стояли примерно по центру, текстовые колонки — выше, а индикатор логина/пароля — ниже.
Задано вертикальное центрирование содержимого всех ячеек `DataGrid`
(`VerticalContentAlignment=Center` и стиль ячейки с нулевым отступом), чтобы элементы каждой
строки выравнивались по одной линии.

Linux/Avalonia-версия уже центрирует ячейки явно и не требовала изменений.

## Исполняемые файлы

- **Windows x64** — `dist/win-x64/ConfigurationManagement.exe`
- **Linux x64** — `dist/linux-x64/ConfigurationManagement`

## Сборка обеих платформ

- Windows: `dotnet build "Configuration Management/Configuration Management.csproj"`
- Linux: `dotnet build "Configuration Management/Configuration Management.csproj" -p:ForceLinux=true`

Обе сборки проходят без ошибок.
