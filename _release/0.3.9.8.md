# 0.3.9.8 — 2026-09-19

## Исправления

- **ESC закрывает открытую подсказку (#261)** — при открытой ToolTip в главном окне первый
  ESC закрывает только подсказку, и только второй сворачивает/прячет окно в трей (WPF и Avalonia).
  Это доработка фикса из `0.3.9.4`, который пользователь отметил как «Не исправлено».

## Почему прошлый фикс не сработал

- **WPF**: закрытие открытого тултипа делалось трюком `ToolTipService.SetIsEnabled(false/true)`,
  который не всегда гасит уже показанный попап; к тому же попап ToolTip живёт вне визуального
  дерева окна (отдельный HWND/Popup) и мог не попадать в обход `Application.Current.Windows`.
  Теперь подсказка закрывается через сам объект `ToolTip` (`IsOpen = false`), плюс добавлен обход
  «хозяина» подсказки по курсору/фокусу.
- **Avalonia**: ESC обрабатывался во всплывающей фазе `KeyDown`, к которой `ToolTip.GetIsOpen`
  на элементе мог быть уже сброшен (таймер показа/оверлейный попап) — открытая подсказка не
  обнаруживалась, окно уходило в трей, а тултип оставался висеть. Теперь ESC ловится на фазе
  туннелирования (Preview), пока `IsOpen` ещё выставлен.

## Версия

- Версия поднята до `0.3.9.8` во всех четырёх полях (`<Version>`, `<AssemblyVersion>`,
  `<FileVersion>`, `<InformationalVersion>`) в `Configuration Management.csproj`.

## Сборка обеих платформ

- Windows: `dotnet build "Configuration Management/Configuration Management.csproj"`
- Linux: `dotnet build "Configuration Management/Configuration Management.csproj" -p:ForceLinux=true`
