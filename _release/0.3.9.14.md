# 0.3.9.14 — 2026-09-20

## Что нового

### Горячие клавиши для избранных (закладки баз 1–9)

Добавлен полноценный набор горячих клавиш для работы с закладками (избранными базами со
назначенным слотом). Закладка — это избранная база с номером слота от 1 до 9. Функция
реализована в обеих версиях: **Windows/WPF** и **Linux/Avalonia**.

#### Колонка закладок в списке баз

- В списке баз добавлена колонка закладок: у избранной базы с назначенным слотом показывается
  бейдж с номером (`1`…`9`). До **9** закладок одновременно.
- Номер слота и порядок закладок хранятся в настройках (`FavoriteHotkeyIds`) и переживают
  перезапуск приложения; у базы отображается вычисляемый номер (`FavoriteHotkeyDisplay`).
- Общая логика работы со слотами вынесена в новый `ViewModels/BookmarkSlotHelper.cs`.

#### Установка закладки

- **Ctrl+щелчок** по строке базы — установить закладку (следующий свободный слот);
- **Ctrl+Shift+P** — установить закладку для выбранной базы;
- **Ctrl+Shift+[1..9]** — назначить конкретный слот;
- меню **Ctrl+B** — открыть панель/меню управления закладками.

#### Перемещение по закладкам

- **Ctrl+[1..9]** — перейти к закладке с указанным номером, раскрывая свёрнутую группу
  (автоматически разворачивается ветка до базы и выполняется прокрутка к строке);
- меню **Ctrl+B** — выбор закладки из списка.

#### Очистка закладок

- **Ctrl+щелчок** по базе с закладкой — снять закладку (номер уходит, избранность сохраняется);
- **Ctrl+Alt+X** — снять все закладки;
- удаление конкретной закладки через окно настроек / меню управления закладками.

#### Запуск закладок

- **Alt+<номер>** — запустить базу в режиме «1С:Предприятие»;
- **Ctrl+Alt+<номер>** — запустить базу в режиме «Конфигуратор»;
- **Alt+E** — запустить все базы, у которых есть закладки.

#### Локализация и тесты

- Добавлены ключи локализации ru/en для новых действий и подсказок
  (`Localization/Languages/ru.json`, `Localization/Languages/en.json`).
- Добавлены тесты: `ConfigurationManagement.Tests/EtapHotkeysFavoritesTests.cs`.
