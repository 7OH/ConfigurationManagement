# 0.3.8.25 — 2026-09-18

## Что исправлено

### #253 — Автоотметка и индикатор «Логин/пароль» в окне определения конфигураций

Наличие логина/пароля определялось только по базовой авторизации `Connection`
и отдельной авторизации Конфигуратора (`ConfiguratorAuth`). Поэтому для баз с раздельной
авторизацией «1С:Предприятия» (`EnterpriseAuth`) галочка по умолчанию не проставлялась,
а индикатор мог гореть красным даже при заданных учётных данных.

Теперь определение идёт через единый резолвер `InfobaseAuthResolver`: логин/пароль считаются
заданными, если хотя бы один режим чтения («Предприятие» или «Конфигуратор») даёт и логин,
и пароль. Это согласует поведение с главным списком и запуском 1С.
