# 0.3.12.32

## Исправлено

### issue #372 — «Форма Задания по расписанию»: комбобоксы показывали ключ

- Поля выбора (Тип действия, Сценарий резервирования, Информационная база, Куда уведомлять,
  единица повтора) показывали ключ (например `Backup`) вместо названия («Резервная копия»).
- Исправление 0.3.12.26 (ItemTemplate + переустановка выбора) не помогало: в WPF связка
  `SelectedValuePath`/`SelectedValue` с кастомным шаблоном `ModernComboBox` отображала в
  закрытом поле сырое значение.
- Теперь выбор ставится через `SelectedItem` (поиск пункта по значению —
  `ScheduledTaskEditViewModel.FindOption`), как в Avalonia-версии.
