Исправлено в версии **0.3.9.262** (Windows/WPF и Linux/Avalonia).

## Создание серверной базы: выбор сервера из списка и ручной ввод «server:port»

Окно «Создать базу» → тип «Клиент-серверная» → поле «Сервер 1С» снова работает как ожидается: выбор сервера из выпадающего списка подставляет строку `server:port` в поле целиком, а ручной ввод (в том числе значения, совпадающего с началом элемента списка — «localhost») идёт свободно, без автозамены и «съедания» символов.

**Что было сломано.** После фикса 0.3.9.242 у редактируемого ComboBox оставался включённым автоподбор ввода (`TextSearch` — значение по умолчанию). При наборе первого символа платформа сама выбирала первый совпадающий элемент списка:

- срабатывал обработчик выбора, который подставлял в поле полный текст элемента — ручной ввод перебивался («буква L съедалась», оставалось `ocalhost`);
- отложенный сброс выделения (`SelectedItem = null`) синхронизировал текст обратно — только что подставленная строка из списка «пропадала».

**Как исправлено.** Автоподбор отключён для поля «Сервер 1С» на обеих платформах:

- WPF: `IsTextSearchEnabled="False"` ([`Views/CreateInfobaseWindow.xaml`](Configuration%20Management/Views/CreateInfobaseWindow.xaml));
- Linux/Avalonia: `IsTextSearchEnabled = false` ([`Views/CreateInfobaseWindow.Avalonia.cs`](Configuration%20Management/Views/CreateInfobaseWindow.Avalonia.cs)).

Теперь событие выбора приходит только от явного выбора элемента списка (мышь/стрелки): строка `server:port` подставляется в поле целиком и остаётся там (отложенный сброс выделения сохранён — повторный выбор того же пункта по-прежнему работает). Ручной ввод не вызывает автоподбора и не перезаписывается; при создании базы используется текущий текст поля — разбор `server:port` на сервер и порт, как в 0.3.9.242.

**Тесты.** Регрессия разбора «server:port» и сборки строк подключения CREATEINFOBASE ([`CreateInfobaseDbServerStringTests.cs`](ConfigurationManagement.Tests/CreateInfobaseDbServerStringTests.cs)). Полный набор `dotnet test` зелёный (1483), кросс-сборка Linux (`dotnet build -p:BuildLinux=true`) без ошибок.

**Как проверить в 0.3.9.262.**

1. Установите версию 0.3.9.262.
2. «Создать базу» → тип «Клиент-серверная» → поле «Сервер 1С»: выберите сервер из выпадающего списка — строка `server:port` появляется в поле целиком.
3. Вручную наберите `localhost` (или другое значение, совпадающее с началом элемента списка): все символы остаются, ничего не мигает и не исчезает; при необходимости дополните порт, например `localhost:1541`.
4. Создайте базу — используется текущий текст поля; порт 1С из «server:port» попадает в команду CREATEINFOBASE и в параметры подключения созданной базы, как в 0.3.9.242.
5. Повторите на Linux (Avalonia).
