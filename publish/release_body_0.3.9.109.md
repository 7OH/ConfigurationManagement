# Управление конфигурациями 1С — v0.3.9.109

Серия из **девяти изменений** (0.3.9.101–0.3.9.109) — исправления регрессов,
доработки окна создания информационных баз и новая функциональность «Сценарии».
Каждое изменение реализовано на **обеих платформах** (Windows/WPF и
Linux/Avalonia).

## Изменения

1. **Выбор версии платформы больше не «перескакивает»** (0.3.9.101, #304) —
   регресс: при выборе частичной версии («8.3» / «8.3.27») и переключении
   фильтра разрядности x32/x64/«Все» выделение возвращалось на папку со старой
   версией. Теперь выбранная версия запоминается и как текущая: фильтры
   разрядности и сортировка A→Z/Z→A сохраняют выделение, результат диалога не
   теряется.

2. **Возвращён горизонтальный скролл списка баз** (0.3.9.102, #309) — регресс
   после добавления новых колонок (0.3.9.86/90): при узком окне колонки значений
   обрезались, добраться до них прокруткой было нельзя. Теперь полоса появляется
   ровно тогда, когда сумма ширин колонок превышает ширину области; заголовок
   прокручивается синхронно со строками, вертикальная прокрутка и фиксированная
   колонка «Название» не затронуты. Shift+колесо над списком прокручивает по
   горизонтали.

3. **Колонка «Последняя копия» отключается из настроек** (0.3.9.103, #311) —
   флажок на вкладке «Настройки → Отображение → Колонки» теперь действительно
   скрывает/показывает колонку (значение читалось из списка, но не передавалось
   в `ApplyDisplaySettings`; работало только контекстное меню заголовка).

4. **Подсветка «зависших» процессов баз** (0.3.9.104, #310) — если процесс
   платформы 1С, подключённый к базе, «не отвечает», точка у имени базы
   становится оранжевой, а при повторных опросах — красной вместо зелёной.
   Windows — `Process.Responding` (PID из WMI), Linux — эвристика по
   `/proc/<pid>/stat` (состояния D/Z считаются «не отвечает»). Подсказка точки
   меняется на «База запущена, процесс не отвечает».

5. **Командная палитра Ctrl+K починена** (0.3.9.105, #312) — окно палитры
   ссылалось в XAML на несуществующий стиль, из-за чего падало с ошибкой при
   каждой попытке открыть (Windows/WPF); та же латентная ошибка исправлена в
   окнах выбора базы и пакетного обновления. Палитра защищена от сбоев
   (try-catch с логированием). В меню «Утилиты» добавлен пункт «Командная
   палитра» с подсказкой горячей клавиши (Ctrl+K, настраивается); сама палитра
   в свой список команд не добавляется.

6. **Кнопка копирования имени базы на сервере** (0.3.9.106, #306) — в окне
   создания серверной информационной базы рядом с полем «Имя базы на сервере»
   появилась кнопка-иконка, копирующая его значение в поле «Наименование».
   Пустое значение поля наименование не затирает.

7. **Флажок «Запретить локальное распознавание речи»** (0.3.9.107, #307) —
   при создании серверной информационной базы рядом с «Блокировкой фоновых
   заданий» появился флажок (как в типовом стартере). В команду CREATEINFOBASE
   добавляется документированный параметр строки подключения `disstt="Y"`;
   значение сохраняется в настройках подключения базы.

8. **Компактное окно создания серверной ИБ + порт СУБД** (0.3.9.108, #305) —
   окно создания клиент-серверной базы стало компактным: поля разложены в две
   колонки (сервер 1С / подключение к СУБД), панель больше не требует прокрутки.
   Рядом с адресом сервера СУБД появилось поле порта с живой подсказкой формата
   `DBSrvr`: для PostgreSQL «host port=NNNN» (порт через пробел, как принимает
   платформа), для MSSQL Server — «host,NNNN». При заполненных адресе и порте
   подсказка показывает, что именно будет передано в команду CREATEINFOBASE.

9. **Сценарии запуска скриптов для баз** (0.3.9.109, #308) — новая функция
   «Сценарии»: пользовательские скрипты/исполняемые файлы выполняются для
   выбранной базы из контекстного меню строки («Выполнить скрипт», хоткей F5)
   или из меню «Утилиты → Настройка сценариев». Параметры сценария поддерживают
   подстановки свойств базы: `%name%`, `%connection.server%`,
   `%connection.database%`, `%connection.filePath%`, `%connection.webUrl%` и
   другие вложенные свойства подключения через точку, а также текущую дату —
   `%date%` (ГГГГ-ММ-ДД) или `%date:формат%` (формат .NET). В окне
   редактирования двойной клик по подстановке вставляет её в позицию курсора
   поля параметров; выбор базы показывает живой пример полной командной строки.
   Окно выбора скрипта (при нескольких сценариях) показывает ту же подсказку и
   запускается двойным кликом. Запуск — через системный shell без ожидания,
   команда пишется в историю запусков базы и в журнал приложения.
