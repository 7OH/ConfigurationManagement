Исправлено в версии **0.3.9.103** (Windows/WPF и Linux/Avalonia).

**Что было сломано.** Колонка «Последняя копия» не отключалась в
«Настройки → Отображение → Колонки»: снимаешь флажок, нажимаешь «OK» — колонка
остаётся на месте. Работал только обходной путь — скрытие через контекстное
меню заголовка колонки.

**Причина.** Видимость колонок на вкладке «Колонки» редактируется в одном
списке с порядком (флажок каждой строки). Значение флажка «Последняя копия»
читалось из списка, но при сохранении не передавалось в `ApplyDisplaySettings`
как аргумент `showLastBackupColumn` — он принимал значение по умолчанию
`true`, и колонка всегда оставалась видимой. Та же ошибка была исправлена
ранее для колонки «Действия» (issue #158) — для «Последней копии» её
повторили при добавлении колонки (0.3.9.86).

**Как исправлено.**

- Windows/WPF — [`Views/SettingsWindow.xaml.cs`](Configuration%20Management/Views/SettingsWindow.xaml.cs):
  в вызов `ApplyDisplaySettings` при сохранении вкладки «Отображение» добавлена
  передача `VisibleOf("LastBackup")`.
- Linux/Avalonia — [`Views/SettingsWindow.Avalonia.cs`](Configuration%20Management/Views/SettingsWindow.Avalonia.cs):
  то же самое через флажок строки `orderItems` («LastBackup»).

Колонка «Последняя копия» теперь скрывается и показывается из настроек на
обеих платформах, состояние сохраняется между запусками.

**Как проверить.**

1. Установите версию **0.3.9.103** (Windows или Linux).
2. «Настройки → Отображение → Колонки», снимите флажок «Последняя копия»,
   нажмите «OK» — колонка исчезает из списка баз.
3. Перезапустите приложение — колонка остаётся скрытой.
4. Верните флажок — колонка снова появляется.
