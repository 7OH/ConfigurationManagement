# Управление конфигурациями 1С — v0.3.9.90

Серия из **двенадцати новых возможностей** (0.3.9.79–0.3.9.90) — от запуска баз из
командной строки и командной палитры до приватных баз, ротации резервных копий и
пакетных операций над выделенными базами. Каждая фича реализована на **обеих
платформах** (Windows/WPF и Linux/Avalonia).

## Новые возможности

1. **Запуск баз из командной строки** (0.3.9.79) — `--run "Имя базы"` запускает
   «1С:Предприятие», `--run "Имя базы" --designer` — Конфигуратор, `--list`
   выводит список баз (имя, тип, Id) для скриптов. База ищется по Id, затем по
   имени. Второй процесс работает без открытия окна; коды возврата: 0 — успех,
   1 — не найдена, 2 — сбой запуска, 3 — внутренняя ошибка. Теперь на любую базу
   можно положить ярлык на рабочий стол или вызывать из внешних лаунчеров.

2. **Избранные базы в меню трея** (0.3.9.80) — секция «Избранные базы (Alt+1…9)»
   со звёздочкой показывается над «Недавними»: запуск одним пунктом или подменю
   «Предприятие / Конфигуратор» — без разворачивания окна. Состав меню
   обновляется автоматически.

3. **Командная палитра Ctrl+K** (0.3.9.81) — быстрый поиск по базам и командам
   интерфейса: Enter запускает «1С:Предприятие», Shift+Enter — Конфигуратор,
   двойной клик — «1С:Предприятие». Избранные базы — вверху списка. Сочетание
   настраивается в «Настройки → Клавиши».

4. **Индикатор «база сейчас запущена»** (0.3.9.82) — зелёная точка рядом с именем
   базы, если у процесса платформы (1cv8) в командной строке найдены параметры
   подключения этой базы (`/F <каталог>` / `/S <сервер>\<база>`). Монитор
   опрашивает процессы раз в 10 секунд (Windows — WMI, Linux — /proc); при
   недоступном WMI тихо деградирует. Флаг не сохраняется в списке.

5. **Дублирование файловой ИБ** (0.3.9.83) — «Дублировать базу» в контекстном
   меню: рекурсивная копия каталога рядом с исходным, новая запись списка
   (новый Id, чистая история запусков, теги наследуются). Подтверждение с
   размером каталога; для запущенных баз и несуществующих каталогов — запрет.

6. **Выборочный экспорт и добавляющий импорт баз** (0.3.9.84) — «Экспорт
   выбранных баз…»: окно-чеклист, выгрузка отмеченных в JSON (формат общего
   экспорта, версия 1). «Импорт баз (добавлением)…»: существующие базы
   распознаются по Id/имени/подключению и снимаются с выбора, недостающие
   группы добавляются вместе с иерархией; текущий список не заменяется.

7. **Приватные базы** (0.3.9.85) — флаг «Приватная база» в свойствах: база
   скрывается из дерева, поиска, тегов, трея, палитры, недавних и `--list`,
   пока профиль не разблокирован его паролем («Открыть приватные базы» в
   «Утилитах»; автоматически при входе с паролем). Без пароля профиля флаг
   включить нельзя; CLI-запуск заблокированной приватной базы отклоняется.

8. **Ротация резервных копий и колонка «Последняя копия»** (0.3.9.86) — в
   сценарии резервирования появились «Хранить копий» (`KeepCount`) и «Удалять
   старше, дней» (`DeleteOlderThanDays`): после каждого успешного копирования в
   каталогах назначения удаляются лишние копии по количеству и возрасту
   (список удалённых — в результате сценария). Новая колонка «Последняя копия»
   показывает дату последней успешной резервной копии (видимость и ширина
   настраиваются).

9. **«Тестирование и исправление» (chdbfl) по расписанию** (0.3.9.87) — новый
   тип задания «Проверка целостности (chdbfl)» для файловых баз: планировщик
   тихо запускает `chdbfl` без окна и дожидается завершения, результат (успех
   либо ошибка с кодом выхода) попадает в задание и журнал.

10. **Пакетное обновление конфигураций из хранилищ** (0.3.9.88) — «Обновление из
    хранилищ» в «Утилитах»: список баз с заполненным адресом хранилища, после
    подтверждения последовательное обновление через конфигуратор
    (`/ConfigurationRepositoryUpdateCfg + /UpdateDBCfg`) с построчным журналом
    (успех/ошибка/время). Запущенные в данный момент базы пропускаются; в
    историю запусков пишется `RepoUpdate`.

11. **Центр обслуживания (дашборд)** (0.3.9.89) — окно в «Утилитах»: таблица
    всех баз с доступностью, последней копией, размером, кэшем, конфигурацией,
    возрастом данных и результатом проверки обновлений. Фильтр «Только
    проблемы» (недоступна / копия старше 7 дней / кэш > 1 ГБ / есть новый
    релиз), кнопка «Открыть базу» и переход по двойному клику.

12. **Мультивыделение и пакетные операции** (0.3.9.90) — Ctrl+щелчок —
    переключение базы, Shift+щелчок — диапазон от «якоря» до цели по видимому
    порядку; помеченные строки получают вторичный фон. В контекстном меню
    появляется блок «Для выделенных (N)…»: назначить тег, переместить в группу,
    добавить в избранное, выполнить сценарий резервирования, проверить
    доступность, удалить.
