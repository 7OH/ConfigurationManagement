Исправлено в версии **0.3.9.272** (Windows/WPF и Linux/Avalonia).

**Что было.**

По учётным записям доступа к ИТС (окно «Учётные записи ИТС») четыре замечания:

1. После удаления записи она оставалась в списке до перезапуска программы — список не обновлялся.
2. Кнопка «Задать основным» на Windows существовала, но была малозаметной: только иконка-звезда без текста (подпись была лишь во всплывающей подсказке), тогда как на Linux это была полноценная текстовая кнопка.
3. Двойной клик по строке ничего не делал — редактировать запись можно было только через кнопку.
4. В списках выбора учётной записи (настройки, тип конфигурации) запись с пустым именем отображалась пустой строкой — пункт «не читался», и выбор падал на виртуальную «Основную».

**Как исправлено.**

1. **Удаление сразу обновляет список**: после удаления записи список перечитывается немедленно — запись исчезает без перезапуска.
2. **Кнопка «Задать основным» стала заметной и единообразной на обеих платформах**: на Windows теперь это иконка + текст «Задать основным» (как было на Linux).
3. **Двойной клик по строке открывает редактор** учётной записи на обеих платформах.
4. **Пустое имя в списках выбора подменяется плейсхолдером «Без имени»** — запись больше не отображается пустой строкой.

Файлы:

- [`ViewModels/ItsAccountsViewModel.cs`](Configuration%20Management/ViewModels/ItsAccountsViewModel.cs:77) — `Delete` теперь вызывает `Reload()`; нормализация имён при построении списков выбора (`ItsAccountSelectionBuilder.Build`) — пустое имя → «Без имени».
- [`Views/ItsAccountsWindow.xaml`](Configuration%20Management/Views/ItsAccountsWindow.xaml:177) — колонка «Задать основным»: иконка + текст; [`Views/ItsAccountsWindow.xaml`](Configuration%20Management/Views/ItsAccountsWindow.xaml:124) — `MouseDoubleClick` на таблице; [`Views/ItsAccountsWindow.xaml.cs`](Configuration%20Management/Views/ItsAccountsWindow.xaml.cs) — обработчик двойного клика.
- [`Views/ItsAccountsWindow.Avalonia.cs`](Configuration%20Management/Views/ItsAccountsWindow.Avalonia.cs:71) — `DoubleTapped` на строке.
- Локализация ru/en — ключ плейсхолдера «Без имени».

**Тесты.** Полный набор `dotnet test` зелёный, кросс-сборка Linux (`dotnet build -p:BuildLinux=true`) без ошибок. Добавлены: кейс «удаление убирает запись из `Load()`» (`ItsAccountsStoreTests`); кейс VM «Add → Delete → коллекция `Rows` больше не содержит удалённой записи»; кейс выборки «пустое имя → плейсхолдер вместо пустой строки».

**Как проверить:**

1. Установите **0.3.9.272** ([релиз v0.3.9.272](https://github.com/sivatorov/ConfigurationManagement/releases/tag/v0.3.9.272)).
2. Откройте «Учётные записи ИТС»: удалите запись — она исчезает из списка сразу.
3. Двойной клик по строке открывает окно редактирования.
4. Проверьте кнопку «Задать основным» на Windows — теперь она с текстом и видна сразу.
5. В настройках / типе конфигурации выберите учётную запись с пустым именем — в списке отображается «Без имени», а не пустая строка.
