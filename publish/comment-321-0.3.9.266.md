Исправлено в версии **0.3.9.266** (Windows/WPF и Linux/Avalonia). Это вторая часть правок окна «Типовые конфигурации» — комфорт работы со списком (первая часть — данные и редактор — вышла в **0.3.9.265**, см. комментарий выше).

**Что сделано по вашим замечаниям.**

1. **Поиск/отбор в списке конфигураций.** Над таблицей появилось поле поиска: фильтрует по наименованию, коду, сегменту адреса, нику и сводке редакций (без учёта регистра, по мере ввода). Очистка — кнопкой или Esc в поле поиска; пустой запрос показывает весь список. Предикат — общий чистый хелпер [`ConfigTypesFilter`](Configuration%20Management/ViewModels/ConfigTypesFilter.cs) на обе платформы.
2. **Список шире по умолчанию.** Окно списка теперь `960×600` (`MinWidth=760`, было 720/600); колонки «Наименование / Сегмент адреса (ник) / Ник / Редакции / Учётная запись» перераспределены пропорционально — длинные наименования не обрезаются.
3. **Подсветка перекрытия типовой пользовательской строкой.** В 0.3.9.265 строка-копия предопределённой помечалась значком ✎★ с подсказкой. Теперь рядом с именем такой строки дополнительно показывается серая подпись «заменена пользовательской» + ToolTip: «Эта пользовательская копия заменяет типовую запись: типовая строка больше не используется и скрыта из списка». Зачёркнутый вариант типовой строки мы сознательно не делаем: по правилу объединения `LoadAll` заменённая типовая строка в списке отсутствует (дублей нет), а факт перекрытия явно виден на копии. Если хочется иначе (например, показывать типовую зачёркнутой) — скажите, сделаем отдельной версией.
4. **«Сегмент УРЛ».** Поле переименовано в «Сегмент адреса (ник)» (в списке и в редакторе записи) и получило ToolTip-пояснение: это часть адреса каталога релизов на releases.1c.ru (после `/project/`, например `AccountingCorp30`), она используется при построении адреса для проверки обновлений конфигурации; если сегмент пуст — берётся ник типовой конфигурации.
5. **Отображение учётной записи.** Колонка показывает текстовое имя записи ИТС либо «Основная» — без непонятных иконок; добавлен ToolTip с пояснением, что это учётная запись ИТС для проверки обновлений этой конфигурации (пусто — «Основная», либо выбранная в настройках). Список учётных записей — в справочнике ИТС (#333).

**Как проверить в 0.3.9.266.**

1. Откройте «Типовые конфигурации» — окно шире; введите в поиске часть имени/кода/ника — список отфильтруется; Esc или «Очистить поиск» возвращает полный список.
2. Отредактируйте типовую конфигурацию (например, ЗУП) — в списке одна строка с ✎★ и серой подписью «заменена пользовательской» (наведите — появится пояснение).
3. В редакторе наведите на поле «Сегмент адреса (ник)» — подсказка о назначении; в списке наведите на колонку учётной записи — подсказка, что это за запись.
