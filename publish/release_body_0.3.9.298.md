# Управление конфигурациями 1С — v0.3.9.298

Дата сборки: 2026-10-03. Версия в csproj: **0.3.9.298** (`Version`/`AssemblyVersion`/`FileVersion`/`InformationalVersion`).

## Исправлено

- **Виснет при старте (issue #343)**: устранён бесконечный layout-цикл расчёта минимальной ширины списка баз на границе `viewport ≈ сумма колонок ± ширина скроллбара` (`CM_COLUMNS` в журнале, ~700 МБ за полминуты, `rows=0`):
  - ширина заголовка больше не зависит от живого `ExtentWidth` внутреннего ScrollViewer дерева (это звено и замыкало петлю «extent → ширина заголовка → сумма колонок → presenterMin → extent») — целевая ширина считается от расчётной суммы колонок ([`SyncHeaderWidthWithList`](Configuration%20Management/Views/MainWindow.Columns.cs));
  - запись `MinWidth` презентера контента выполняется только при фактическом изменении значения (защита от инвалидации раскладки на каждый `ScrollChanged`);
  - переключение панели `VirtualizingStackPanel`/`StackPanel` получило гистерезис (запас больше 2×ширины скроллбара) и дебаунс (не чаще раза в 500 мс), а до завершения стартовой инициализации дерева стратегия панели не меняется вовсе — ранний переход на обычный `StackPanel` материализовал всё дерево и «вешал» приложение на загрузке избранного;
  - диагностика `CM_COLUMNS` больше не пишется в цикле: по умолчанию одна запись на сессию (стартовый дамп), постоянный лог — только с env `CM_COLUMNS_TRACE=1`.

- **Читаемые имена файлов сценариев (issue #344)**: файлы в `scripts/scenarios` получают имя `<Имя>.<Id>.script.json`, например `Calc.19fb08b20a2b434588e6d857479c50f0.script.json`, — в папке сразу видно, какой сценарий лежит в файле. Старые файлы `<id>.script.json` читаются без изменений и мигрируют на новое имя при первом редактировании сценария; коллизии одинаковых имён исключены суффиксом-Id; санитизация имени: недопустимые символы → «_», обрезка длины, зарезервированные имена устройств Windows и скрытые файлы Linux получают префикс «_», кириллица сохраняется ([`ScriptScenarioStore.cs`](Configuration%20Management/Services/ScriptScenarioStore.cs)).

- **Горизонтальный скрол (issue #309)**: проверка разблокирована фиксом #343 (приложение больше не зависает при старте); инструментальный лог не раздувается (одна строка `CM_COLUMNS` за сессию по умолчанию), `EnsureHorizontalReach` (докрутка до последних колонок после применения настроек) сохранён.
