# Управление конфигурациями 1С — v0.3.9.155

Серия из **десяти изменений** (0.3.9.146–0.3.9.155) по восьми открытым issues автора:
устранение регресса пустых незакрываемых окон редактора сценария и создания ИБ (#308,
#305), доработки запуска и редактора сценариев (#308, три этапа), локализация и размер
окна сравнения конфигураций (#316), единое поле «Сервер 1С:порт» (#305), подсветка
закреплённых копий при Shift-выделении (#314), горизонтальная прокрутка после настроек
колонок (#309), стабильный выбор версии платформы при смене разрядности (#304), URL
веб-серверных баз в колонке «Сервер/База» (#319) и читаемый UTF-8 в JSON-файлах
(#320). Каждое изменение реализовано на **обеих платформах** (Windows/WPF и
Linux/Avalonia).

## Изменения

1. **Окна редактора сценария и создания ИБ: устранён регресс пустого незакрываемого
   окна (0.3.9.146, #308/#305)** — причиной был хрупкий авторазмер `SizeToContent=Height`,
   схлопывавший окно в пустой прямоугольник при модальном показе. Оба окна снова
   открываются с явной высотой: редактор сценария — фиксированной (640 WPF / 680
   Avalonia) со внутренним скроллом, окно создания ИБ подгоняет высоту под содержимое
   один раз после первой отрисовки и удерживается в рабочей области экрана при смене
   типа «Файловая ↔ Клиент-серверная». Общий расчёт размеров/позиции вынесен в чистый
   [`Services/WindowSizeMath.cs`](Configuration%20Management/Services/WindowSizeMath.cs)
   и покрыт юнит-тестами.

2. **Сценарии: видимое окно выполнения и корректная команда PowerShell (0.3.9.147,
   #308)** — исправлена инверсия флага `createNoWindow`: снятая галка «Скрывать окно»
   снова показывает консольное окно при запуске скрипта. Командная строка для
   PowerShell собирается с разделителем `;` вместо `&&` (`powershell -NoProfile -Command
   cd "…"; …`), который PowerShell 5.1 не поддерживает; cmd/sh — как раньше, `&&`.

3. **Сценарии: комбобокс базы по имени и перенос галки «Скрывать окно» (0.3.9.148,
   #308)** — закрытый комбобокс «База для примера подстановок» снова показывает имя
   базы (явный `ItemTemplate` вместо `DisplayMemberPath`, выбор переустанавливается после
   показа окна), превью командной строки заполняется и меняется при выборе базы. Галка
   «Скрывать окно скрипта» перенесена на одну строку с «Интерпретатор» (WPF + Avalonia).

4. **«Сравнение конфигураций»: имя базы в комбобоксе и окно по содержимому (0.3.9.149,
   #316)** — комбобокс «База» показывает имя выбранной базы, а не имя типа
   (`ItemTemplate`, поиск по `Id`, повторный выбор после показа окна); окно подстраивает
   высоту под содержимое (схема из 0.3.9.146 через `WindowSizeMath.ClampHeight`) —
   пустого места внизу нет ни в одном из режимов «База ↔ .cf» / «.cf ↔ .cf».

5. **Создание серверной базы: единое поле «Сервер 1С:порт», окно не уходит за край
   (0.3.9.150, #305)** — поля «Сервер 1С» и «Порт сервера 1С» снова объединены в одно
   редактируемое поле `server:port` (как в окне правки свойств базы): строка из списка
   заполняется целиком (`srv1c:1541`), отдельное поле порта убрано. Разбор
   `server:port` вынесен в чистый `CreateInfobaseService.ParseServerPort` (тесты
   включают «лишние двоеточия»). При смене типа окно пересчитывает высоту и поднимается,
   если нижняя часть уходит за нижний край рабочей области (WPF — `WorkArea`, Avalonia —
   `WorkingArea`, общий `WindowSizeMath.FitTop`).

6. **Мультивыделение: Shift-диапазон не подсвечивает закреплённые копии (0.3.9.151,
   #314)** — закреплённые строки узла «Закреплённые» больше не получают вторичный фон
   «для выделенных», когда реальная база легитимно попадает в Shift-диапазон: WPF —
   триггер фона заменён на `MultiDataTrigger` с маркером `Tag="pinned"`, Avalonia —
   карточка закреплённой строки не подписывается на `IsBatchSelected`. Якорь сохранён:
   клик по закреплённой строке по-прежнему разворачивается до реальной базы.

7. **Горизонтальная прокрутка после настроек колонок (0.3.9.152, #309)** — пересчёт
   минимальной ширины списка привязан напрямую ко всем точкам применения настроек
   колонок, а не только к выравниванию заголовка: прямой пересчёт при старте
   (`OnWindowLoaded`, не зависит от наличия строк), после завершения фоновой
   инициализации, при изменении видимости/ширин и порядка колонок; на Avalonia
   `SyncHeaderWidthWithList` тоже пересчитывает минимум контента. Полоса дотягивает до
   последней колонки при сохранённых скрытых/растянутых колонках (анти-регресс #255
   сохранён).

8. **Выбор версии платформы: сохранение папки выбранной версии при смене разрядности
   (0.3.9.153, #304)** — устранена причина «скачка» 8.5.1 → 8.5: суффикс разрядности в
   результате диалога добавляется только когда у версии реально есть видимый лист этой
   разрядности (новый `BuildResultVariant`), а восстановление выделения по листу
   «8.5.1 (64)» отдаёт приоритет точному листу перед папкой группы и линией
   (`FindBestNode`). Поведение #251/#142 сохранено; сценарии покрыты новыми
   юнит-тестами.

9. **Колонка «Сервер/База»: URL для веб-серверных баз (0.3.9.154, #319)** — для баз
   вида «Веб-сервер» колонка показывает URL публикации (`Connection.WebUrl`) вместо
   пустоты; при отсутствии URL — имя базы или «—». Исправление в единой точке
   `Models/Infobase.ServerDatabaseDisplay`, поэтому URL виден сразу в списке баз и в
   карточке базы (WPF + Avalonia). Добавлены тесты `InfobaseDisplayTests`.

10. **Читаемый UTF-8 в JSON-файлах сценариев, резервирования и расписания (0.3.9.155,
    #320)** — новые файлы сохраняются с русскими буквами как есть
    (`"Name": "Тест 2"`), а не в виде `\u0422\u0435\u0441\u0442 2`: во всех трёх
    хранилищах (`ScriptScenarioStore`, `BackupScenarioStore`, `ScheduledTaskStore`)
    задан `Encoder = JavaScriptEncoder.UnsafeRelaxedJsonEscaping`. Чтение обратно
    совместимо: старые файлы с `\uXXXX` разбираются корректно. Добавлены тесты на
    читаемый UTF-8 и совместимость; весь набор — 703/703.
