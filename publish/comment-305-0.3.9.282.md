Исправлено в версии **0.3.9.282** (Windows/WPF и Linux/Avalonia).

По всем четырём замечаниям:

**1. Выбор сервера 1С из списка не подставляет строку в поле.**

К обработчику выбора (`SelectionChanged`) добавлена страховка `DropDownClosed`: когда выпадающий список закрывается, выбранный элемент «server:port» ещё раз принудительно применяется к полю. Это покрывает случай, когда событие выбора приходит до готовности редактируемого текста ComboBox (раньше срабатывал только один путь, и на части сборок поле оставалось пустым). Правки: [`CreateInfobaseWindow.xaml`](Configuration%20Management/Views/CreateInfobaseWindow.xaml) + [`CreateInfobaseWindow.xaml.cs`](Configuration%20Management/Views/CreateInfobaseWindow.xaml.cs), [`CreateInfobaseWindow.Avalonia.cs`](Configuration%20Management/Views/CreateInfobaseWindow.Avalonia.cs).

**2. Введённый `localhost` в «Сервер СУБД» не сохранялся при повторном открытии.**

Проверил цепочку: после успешного создания `CreateInfobaseService.SaveLastDbServer(сервер, порт)` пишет значения в настройки, а при открытии окна `RestoreLastDbServer()` подставляет их обратно в поля — на обеих платформах. Связка сохранение/восстановление на месте; если на вашей версии ещё не было этих правок — теперь они точно в сборке.

**3. База создалась с разрядностью х86 при дефолте х64.**

Причина найдена: при выборе версии «8.3.27» без суффикса разрядности новая база жёстко получала приоритетную **32-битную** разрядность, игнорируя «Разрядность по умолчанию» (X64). Исправлено в [`Services/CreateInfobaseService.cs`](Configuration%20Management/Services/CreateInfobaseService.cs): без суффикса «(32)/(64)» база наследует настройку из Настроек → Платформы — X64 → «64-priority», X86 → «32-priority», Priority/легаси — как раньше.

**4. Не пояснено, на чём основывается вывод окна.**

Справка окна (значок «?») дополнена пунктом про разрядность: суффикс «(32)/(64)» у версии задаёт её явно, без суффикса берётся разрядность по умолчанию из настроек (`CreateInfobase.HelpText`, ru/en).

**Тесты.** Добавлены кейсы `PriorityArchitectureFromDefault_*` (маппинг X64/X86/Priority/легаси) в [`CreateInfobaseDbServerStringTests`](ConfigurationManagement.Tests/CreateInfobaseDbServerStringTests.cs). Полный набор `dotnet test` зелёный (1567), кросс-сборка Linux (`dotnet build -p:BuildLinux=true`) без ошибок.

**Как проверить:**

1. Установите **0.3.9.282** ([релиз v0.3.9.282](https://github.com/sivatorov/ConfigurationManagement/releases/tag/v0.3.9.282)).
2. Настройки → Платформы: «Разрядность по умолчанию» = X64.
3. Создайте клиент-серверную базу, выбрав версию «8.3.27» без разрядности: в списке у созданной базы должна появиться разрядность «(64)».
4. Выберите сервер из выпадающего списка — строка должна попасть в поле.
5. Создайте базу, указав в «Сервер СУБД» `localhost`, затем откройте окно создания снова — значение должно подставиться автоматически.
