Исправлено в версии **0.3.9.297** (Windows/WPF и Linux/Avalonia).

**Что было сделано.**

У окна «Проверка обновлений» и окна обновления платформы общий корень — обработка
редиректа 302 сайта 1С. Проверка обновлений ходит на releases.1c.ru через тот же
сервис `OneCUpdatesService`, поэтому фикс один на все окна.

1. **Редирект 302 без Location.** Если сервер ответил 302, но без заголовка
   Location, это распознаётся и выводится понятная ошибка (требуется вход на сайт
   1С) вместо «HTTP 302 / Редирект не пройден» без объяснений.

2. **Редирект на login.1c.ru с service-параметром — программный вход.** Раньше
   после GET формы и POST логина вход считался выполненным без обращения к
   `security_check?ticket=…`, и повторный запрос каталога снова получал 302. Теперь
   вход доводится до конца: GET формы по полному URL редиректа, извлечение токена
   `execution`, POST учётных данных, ручное прохождение редиректов после POST с
   накоплением сессионных cookie, повтор исходного запроса.

3. **Учётные данные ИТС из справочника.** Креды для входа берутся из справочника
   учётных записей ИТС (`its_accounts.json`) через `IItsAccountsStore`; устаревшие
   поля настроек — только запасной вариант. Раньше store в сервис не попадал, и
   при пустых старых полях вход даже не начинался.

4. **Каталоги релизов после входа.** Каталоги конфигураций (например,
   `AccountingCorp30`, `HRM`) запрашиваются повторно после успешного входа —
   заполняются «Последняя версия» и «Ссылка на каталог релизов».

**Тесты.** `UpdateCheckCatalogTests`: сценарий «GET каталога → 302 на login.1c.ru →
форма → POST → 302 на security_check?ticket=… → GET → 200 → каталог получен»;
302 без Location → понятная ошибка; без кредов → AuthRequired. Существующие тесты
сценариев 302 продолжают проходить.

**Как проверить:**

1. Установите версию **0.3.9.297**.
2. Настройте учётную запись ИТС в «Общих настройках» (справочник учёток).
3. Откройте «Проверка обновлений» для любой типовой конфигурации: должна
   загрузиться таблица версий каталога, а не «HTTP 302».
4. В журнале видны шаги входа (`Вход на portal.1c.ru выполнен`) и имя учётки без
   пароля.
