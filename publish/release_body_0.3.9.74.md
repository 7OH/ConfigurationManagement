# Управление конфигурациями 1С — v0.3.9.74

Исправления по обратной связи из issues **#294, #296, #300, #301**.

## Блокировка приложения: постоянное состояние (#294 → 0.3.9.71)

«Блокировка приложения» больше не сводится к мгновенному окну разблокировки:

- Блокировка — **состояние сеанса**: клиентская область закрывается оверлеем
  «Приложение заблокировано», ввод в окно (мышь, клавиатура, горячие клавиши)
  не проходит.
- Окно ввода пароля закрываемое (крестик, «Отмена», Esc) — закрытие **не снимает**
  блокировку; любое взаимодействие с окном снова открывает окно ввода.
- Снятие блокировки — только верным паролем. Фокус в поле пароля ставится надёжно.
- Windows/WPF и Linux/Avalonia.

## Компактный режим: строка базы сжимается до высоты группы (#296 → 0.3.9.72, Windows)

- Кнопки звезды/булавки больше не раздуваются неявным стилем MaterialDesign
  (было ~32px) — стали размером с иконку.
- Кнопки действий строки в компактном режиме — 18px вместо 24–31px.
- Кнопка разворота группы в компактном режиме 26 → 18.
- Замер: строка базы без тегов 32px → **19–20px**, группа 28px → **18–25px**.
  Обычный режим не изменён.

## Linux: плашка Alt+N не накладывается на булавку (#300 → 0.3.9.73)

- Колонка «Избранное» расширена 28 → 40: содержимое кнопки звезды с плашкой
  слота (~35–39px) помещается в свою колонку и не задевает колонку закрепления.

## Linux: клик выделяет строку под курсором (#301 → 0.3.9.74)

- В дереве больше нет дублей данных: строки узла «Закреплённые» ссылаются на
  обёртку `PinnedInfobaseItem`, сам экземпляр базы присутствует в дереве один раз.
- Штатная разметка выделения Avalonia больше не может подсветить чужую копию;
  «Найти в списке», восстановление выделения и клавиатурная навигация всегда
  попадают в единственную строку базы.
