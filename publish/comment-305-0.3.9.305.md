Исправлено в версии **0.3.9.305** (Windows/WPF и Linux/Avalonia).

**Что было.**

«Имя сервера СУБД сохраняется — почти. Сохраняется только по кнопке отмена. При успешном создании базы — не сохраняется. Попутно предложу доработку — сохранять ещё и тип базы».

Причина найдена (Windows/WPF): после успешного создания клиент-серверной базы главное окно запускало отложенное сохранение настроек (`ScheduleSaveSettings`), а метод `SaveSettings()` переписывал файл настроек «с нуля» — новым экземпляром `AppSettings` с фиксированным списком полей, **без** только что записанных `LastCreateDbServer`/`LastCreateDbPort`. Значение «Сервер СУБД» терялось примерно через 150 мс после успешного создания. При отмене `SelectedInfobase` не менялся, отложенного сохранения не было — поэтому при закрытии без создания сервер сохранялся. Это в точности симптом из описания.

**Что сделано.**

1. [`ViewModels/MainViewModel.Launch.cs`](Configuration%20Management/ViewModels/MainViewModel.Launch.cs): `SaveSettings()` больше не создаёт новый `AppSettings`, а **мутирует загруженный экземпляр** (`LoadSettings()` + те же присваивания полей VM). Поля, которые VM не ведёт (`LastCreateDbServer`, `LastCreateDbPort` и др.), больше не теряются ни при каком сохранении — гонка с `ScheduleSaveSettings` устранена.
2. Запоминается последний использованный **тип базы** (`LastCreateDbType`, «Файловая»/«Клиент-серверная»): новое поле в [`Models/AppSettings.cs`](Configuration%20Management/Models/AppSettings.cs); [`Services/CreateInfobaseService.SaveLastDbServer(dbServer, dbPort, isClientServer)`](Configuration%20Management/Services/CreateInfobaseService.cs) сохраняет и тип — как после успешного создания, так и при закрытии окна (в файловом режиме сохраняется только тип, ранее сохранённые сервер/порт не затираются).
3. При открытии окна создания восстанавливается и тип, и сервер/порт ([`Views/CreateInfobaseWindow.xaml.cs`](Configuration%20Management/Views/CreateInfobaseWindow.xaml.cs), [`Views/CreateInfobaseWindow.Avalonia.cs`](Configuration%20Management/Views/CreateInfobaseWindow.Avalonia.cs)). Avalonia-версия получила ту же доработку (там перезаписи настроек не было, но тип не запоминался).

**Как проверить:** обновитесь до **0.3.9.305**; создайте клиент-серверную базу → закройте окно → откройте окно создания снова: поле «Сервер СУБД» и тип «Клиент-серверная» подставлены. Затем создайте файловую базу → откройте окно → выбран тип «Файловая». Ввод без создания (закрытие без создания) по-прежнему сохраняется. Проверьте, что прочие настройки (тема, колонки, горячие клавиши, позиция окна) не слетели.
