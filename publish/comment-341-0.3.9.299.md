Исправлено в версии **0.3.9.299**.

Что сделано:
- **Ctrl+клик по «плюсику» группы** теперь работает так же, как Ctrl+клик по названию: сворачивает/разворачивает **всю ветку** (сама группа + все подгруппы рекурсивно) на обеих платформах — Windows/WPF и Linux/Avalonia.
- Команда ветки применяется ровно один раз — без конфликта с обычным кликом по кнопке разворота (обычный клик по «плюсику» работает как раньше).
- Текущая строка и выделение не меняются.
- Добавлен тест полного цикла toggle с восстановлением поддерева — соседние ветки не трогаются (`ToggleBranch_ToggleTwice_RestoresSubtreeAndLeavesNeighbors`).

Как проверить: обновитесь до 0.3.9.299, зажмите Ctrl и кликните по «плюсику» группы (и свёрнутой, и развёрнутой) — ветка должна сворачиваться/разворачиваться целиком, текущая строка и выделение не должны меняться.
