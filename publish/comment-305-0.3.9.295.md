Исправлено в версии **0.3.9.295**.

Что сделано (по трём пунктам):

1. **Выбор сервера 1С из списка.** Подстановка «server:port» в поле усилена на обеих платформах: после выбора элемента текст остаётся в поле даже если ComboBox «сбрасывает» выделение (страховка от затирания поля при синхронизации Text).

2. **Предупреждение «версия отличается».** Уточнена логика и текст. Версия на сервере не «догадывается» по сети — она берётся из вашего списка баз приложения: если на том же сервере (адрес без порта и регистра) есть клиент-серверные базы с версией, отличающейся по первым двум числам от выбранной — появляется предупреждение. Сравнение серверов стало устойчивым к порту («localhost:1541» ≡ «localhost»). Текст сообщения переписан: «В вашем списке баз есть клиент-серверные базы на сервере "{сервер}" с версией платформы {версия}, которая отличается от выбранной ({выбранная}). Продолжить создание?».

3. **Разрядность «8.3.27 [x86]».** Найден и исправлен корень: выбор версии без суффикса разрядности трактовался как «явно x86», хотя фактически запускалась x64-версия (по настройке «Разрядность по умолчанию»). Теперь без суффикса база наследует режим из настроек: при дефолте X64 новая база получает «64-priority» (в списке — чистая версия без «[x86]»); суффикс «(32)/(64)» в выбранной версии по-прежнему задаёт разрядность явно.

Добавлены тесты на все три случая (разрядность без суффикса/с суффиксом, сравнение серверов с портом и регистром, снятие суффикса с чистой версии).

Обновитесь до 0.3.9.295 и проверьте: выберите сервер из списка, создайте базу с версией без суффикса при дефолте X64 — в списке должна появиться база без «[x86]».
