Исправлено в версии **0.3.9.150** (Windows/WPF и Linux/Avalonia) — сервер 1С снова выбирается одним полем, окно не уходит за край экрана при смене типа.

**Что было.** После выбора сервера в поле «Сервер 1С» оставался только порт, а само поле обрезалось: сервер и порт были разделены на два поля. Базу обычно выдают вместе с портом и копируют одним целым.

**Как исправлено.**

- Поля «Сервер 1С» + «Порт сервера 1С» снова объединены в одно редактируемое поле `server:port`, как в окне правки свойств базы ([`Views/CreateInfobaseWindow.xaml`](Configuration%20Management/Views/CreateInfobaseWindow.xaml) и [`Views/CreateInfobaseWindow.Avalonia.cs`](Configuration%20Management/Views/CreateInfobaseWindow.Avalonia.cs)). При выборе строки из списка поле заполняется целиком (например, `srv1c:1541`), отдельное поле порта убрано — макет стал компактнее.
- Разбор строки `server:port` на имя сервера и порт вынесен в чистый `CreateInfobaseService.ParseServerPort` и покрыт юнит-тестами, включая «лишние двоеточия» ([`CreateInfobaseDbServerStringTests.cs`](ConfigurationManagement.Tests/CreateInfobaseDbServerStringTests.cs)). Порт сервера 1С не смешивается с портом СУБД (разные поля модели).
- При смене типа «Файловая ↔ Клиент-серверная» окно пересчитывает высоту под содержимое и поднимается, если его нижняя часть уходит за нижний край рабочей области: WPF — через `SystemParameters.WorkArea` + чистый `WindowSizeMath.FitTop`, Avalonia — через `Screens.ScreenFromWindow(...).WorkingArea` с тем же helper ([`Services/WindowSizeMath.cs`](Configuration%20Management/Services/WindowSizeMath.cs)).

Тесты `dotnet test` (672) и сборка Linux-ветки (`dotnet build -p:BuildLinux=true`) проходят без ошибок.

**Как проверить.**

1. Установите версию **0.3.9.150**.
2. «Создать базу» → тип «Клиент-серверная» → поле «Сервер 1С»: в выпадающем списке строки вида `server:port`; при выборе заполнено одно поле целиком (не только порт, ничего не обрезается).
3. Создайте базу: `Srvr` и порт попадают в команду создания и в параметры подключения созданной базы.
4. Переместите главное окно ближе к нижнему краю экрана → «Создать базу» → смените тип: окно поднимается, нижняя часть не уходит за экран.
5. Проверьте запоминание «Сервера СУБД» и кликабельную подсказку «Например localhost» (функции 0.3.9.145 не сломаны).
6. Повторите на Linux (Avalonia).
