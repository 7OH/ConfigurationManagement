# Управление конфигурациями 1С — v0.3.9.253

Серия из **двадцати улучшений** (цикл 0.3.9.234–0.3.9.253) по собственной дорожной
карте проекта, сгруппированных в восемь пакетов: точечные исправления окна правки базы
и импорта (П1), работа с деревом баз — мультивыделение, «Для выделенных»,
клавиатурная навигация и запуск по Enter (П2), выбор сервера с портом (П3), типовые
конфигурации, связывание с конфигурацией и проверка обновлений (П4), справочник
учётных данных ИТС (П5), автообновление платформы 1С и скачивание нужного дистрибутива
(П6), скрипты и пикер версий платформы (П7), монитор серверов через RAC и
горизонтальный скролл колонок (П8). Каждое улучшение реализовано на **обеих
платформах** (Windows/WPF и Linux/Avalonia) с юнит-тестами.

## Изменения

### П1. Точечные исправления (0.3.9.234–237)

1. **0.3.9.234 — [#332](https://github.com/sivatorov/ConfigurationManagement/issues/332)**
   — обработка ссылки на базу с сегментом локали (`/ru/`): нормализация URL при запуске
   файловой и серверной базы на обеих платформах, юнит-тесты нормализации.
2. **0.3.9.235 — [#325](https://github.com/sivatorov/ConfigurationManagement/issues/325)**
   — подпись «Конфигурация» в окне свойств базы поднята и выровнена по сетке на обеих
   платформах.
3. **0.3.9.236 — [#329](https://github.com/sivatorov/ConfigurationManagement/issues/329)**
   — список шрифтов строится из установленных в системе (ленивая загрузка в WPF),
   выбор сохраняется по тексту поля, невалидный ввод валидируется.
4. **0.3.9.237 — [#327](https://github.com/sivatorov/ConfigurationManagement/issues/327)**
   — удалённые пустые группы больше не возвращаются при импорте из `ibases.v8i`
   (tombstone-список, юнит-тесты импорта).

### П2. Дерево баз: выделение и клавиатура (0.3.9.238–241)

5. **0.3.9.238 — [#326](https://github.com/sivatorov/ConfigurationManagement/issues/326)**
   — выделение в секции закреплений: единый маркер секции, корректная работа
   множественного выделения для закреплённых баз.
6. **0.3.9.239 — [#313](https://github.com/sivatorov/ConfigurationManagement/issues/313)**
   — правый клик по выделенным не теряет набор: контекстное меню применяется ко всей
   выделенной группе, а не только к строке под курсором.
7. **0.3.9.240 — [#331](https://github.com/sivatorov/ConfigurationManagement/issues/331)**
   — навигация курсором по дереву произвольной глубины (стрелки вверх/вниз/влево/вправо,
   переходы между секциями закреплений и списка).
8. **0.3.9.241 — [#328](https://github.com/sivatorov/ConfigurationManagement/issues/328)**
   — запуск базы по Enter в списке и в дереве; не срабатывает в текстовых полях и
   диалогах, учитываются пользовательские горячие клавиши.

### П3. Выбор сервера с портом (0.3.9.242–243)

9. **0.3.9.242 — [#305](https://github.com/sivatorov/ConfigurationManagement/issues/305)**
   — создание серверной базы: порт 1С передаётся в `CREATEINFOBASE`, сервер выбирается
   из общего списка в формате `host:port`.
10. **0.3.9.243 — [#335](https://github.com/sivatorov/ConfigurationManagement/issues/335)**
    — диагностика подключения: сервер задаётся вместе с портом, порты по серверу
    запоминаются в отдельном файле, учтено хранилище 1С (1540/1541/1545).

### П4. Типовые конфигурации и проверка обновлений (0.3.9.244–246)

11. **0.3.9.244 — [#321](https://github.com/sivatorov/ConfigurationManagement/issues/321)**
    — окно типовых конфигураций: восстановление предопределённого набора «Восстановить
    типовые», добавление/удаление записей, ЗУП 3.0 и 3.1 без дублей (составной ключ).
12. **0.3.9.245 — [#322](https://github.com/sivatorov/ConfigurationManagement/issues/322)**
    — связь с конфигурацией: кнопки в одну строку, автоопределение по приоритету
    сегмента URL — ЗУП вместо ошибочного БУХ.
13. **0.3.9.246 — [#323](https://github.com/sivatorov/ConfigurationManagement/issues/323)**
    — проверка обновлений: каталог релизов из свойств конфигурации, понятная ошибка при
    отсутствии ника ИТС, прослежена вся цепочка до страницы 1С.

### П5. Учётные данные ИТС (0.3.9.247)

14. **0.3.9.247 — [#333](https://github.com/sivatorov/ConfigurationManagement/issues/333)**
    — новый справочник учётных данных ИТС: окно списка/редактора, миграция старых полей
    настроек (идемпотентно), маскирование пароля, правила записи «Основной» на
    граничных случаях.

### П6. Обновление платформы 1С (0.3.9.248–249)

15. **0.3.9.248 — [#334](https://github.com/sivatorov/ConfigurationManagement/issues/334)**
    — автообновление платформы: понятная ошибка при недоступном каталоге релизов,
    устранено «мигание» статуса в окне обновления.
16. **0.3.9.249 — [#330](https://github.com/sivatorov/ConfigurationManagement/issues/330)**
    — скачивание нужной версии платформы 1С: окно выбора версии и разрядности, загрузка
    дистрибутива **без автоматической установки** (только «скачать → показать папку →
    запустить установщик по желанию пользователя»).

### П7. Скрипты и выбор платформы (0.3.9.250–251)

17. **0.3.9.250 — [#308](https://github.com/sivatorov/ConfigurationManagement/issues/308)**
    — сценарии-скрипты: опции уведомления о запуске и «не закрывать окно» после
    выполнения, юнит-тесты хвоста команды для cmd/PowerShell/sh.
18. **0.3.9.251 — [#304](https://github.com/sivatorov/ConfigurationManagement/issues/304)**
    — выбор версии платформы: при смене разрядности выделенный узел не уходит наверх,
    дерево восстанавливает позицию и скроллится к нему.

### П8. Монитор серверов и колонки (0.3.9.252–253)

19. **0.3.9.252 — [#324](https://github.com/sivatorov/ConfigurationManagement/issues/324)**
    — монитор серверов: адрес кластера в формате `rac host:port`, порт по умолчанию 1540,
    устойчивый парсер вывода rac для разных версий и локалей.
20. **0.3.9.253 — [#309](https://github.com/sivatorov/ConfigurationManagement/issues/309)**
    — горизонтальный скролл при ручном перетаскивании колонок: полоса прокрутки
    расширяется/сужается живьём во время перетаскивания (дебаунс в WPF и Avalonia,
    дорогие замеры только на завершении), колонки с авто-сохранением ширины учитываются.
