# v0.3.12.5 — Выбор окна при нескольких закачках (issue #359)

Windows/WPF и Linux/Avalonia.

## Исправлено

- **Клик по тексту индикатора фоновых загрузок главного окна выбирает нужное
  окно (issue #359)** — раньше клик всегда открывал окно скачивания платформы,
  а при нескольких закачках из разных окон это было «открывается случайное
  окно». Теперь:
  - если активные скачивания идут из **разных окон** (дистрибутив платформы +
    цепочка обновлений и т.п.) — над индикатором всплывает небольшое меню
    выбора «окно: файл (45 %)», пункт открывает соответствующее окно;
  - если качается что-то одно — окно открывается сразу, без лишнего клика.

  Привязка идентификатора закачки к окну: `platform:` → «Скачивание версии
  платформы 1С», `platform-update:` → «Обновление платформы 1С»,
  `update:`/`chain:` → окно «Проверка обновлений» соответствующей ИБ.

- **Индикатор фоновых загрузок заработал на Linux** — общий ViewModel-файл
  индикатора не подключался к Linux-сборке (и подписка на менеджер загрузок
  там не выполнялась): панель индикатора в Avalonia оставалась скрытой, хотя
  UI её собирался. Файл подключён к Linux-сборке, подписка добавлена в
  конструктор Avalonia-версии `MainViewModel`, как в WPF. Заодно клик по тексту
  индикатора в Avalonia стал работать (раньше текст был некликабельным).

Полный набор `dotnet test` зелёный (**2298**); сборка решения (`dotnet build`) и
кросс-сборка Linux (`dotnet build -p:ForceLinux=true`) без ошибок.
