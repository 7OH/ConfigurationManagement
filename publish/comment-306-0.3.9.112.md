Исправлено в версии **0.3.9.112** (Windows/WPF и Linux/Avalonia).

**Что было не так.** Кнопка копирования (иконка копирования) стояла у поля
«Имя базы на сервере» — то есть у самого источника значения, хотя нужна она
у поля «Наименование», куда значение переносится.

**Как исправлено.** Кнопка перенесена к полю «Наименование»; направление
копирования не изменилось: клик по кнопке у «Наименования» копирует значение
из «Имя базы на сервере» в «Наименование». У поля «Имя базы на сервере»
кнопки больше нет. Пустое значение Ref наименование не затирает (поведение
сохранено).

- Windows/WPF — [`Views/CreateInfobaseWindow.xaml`](Configuration%20Management/Views/CreateInfobaseWindow.xaml):
  `NameBox` обёрнут в Grid (TextBox + кнопка-иконка ContentCopy), у `RefBox`
  кнопка убрана (простой TextBox); обработчик `OnCopyRefToName_Click` не менялся.
- Linux/Avalonia — [`Views/CreateInfobaseWindow.Avalonia.cs`](Configuration%20Management/Views/CreateInfobaseWindow.Avalonia.cs):
  кнопка `copyRef` перенесена к строке `_nameBox`, у `_refBox` убрана;
  `CopyRefToName()` не менялась (Ref → Name, пустой Ref не затирает Name).

**Как проверить.**

1. Установите версию **0.3.9.112** (Windows или Linux).
2. Откройте окно создания ИБ и выберите тип «Клиент-серверная».
3. Заполните «Имя базы на сервере», затем нажмите кнопку-иконку рядом с полем
   «Наименование» — значение из «Имя базы на сервере» появится в «Наименовании».
4. Очистите «Имя базы на сервере» и снова нажмите кнопку у «Наименования» —
   наименование не изменится (пустой Ref не затирает Name).
5. Убедитесь, что у поля «Имя базы на сервере» кнопки больше нет.
