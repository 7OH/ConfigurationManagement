Исправлено в версии **0.3.9.269** (Windows/WPF и Linux/Avalonia).

**Что сделано по вашим замечаниям к окну «Диагностика подключения».**

1. **Кнопки больше не пропадают при узком окне.** Панель команд разделена на две строки:
   - строка 1: «Сервер:» (адрес), «Серверы:» (выпадающий список), «Порт:» и кнопка **«Проверить»**;
   - строка 2: **«Проверить порты 1С»**, **«Проверить хранилище»**, **«Повторить»**, **«Закрыть»**.
   Раньше поля и все пять кнопок лежали в одном горизонтальном ряду — при сужении окна кнопки обрезались за краем. Минимальная ширина окна увеличена (680 → 760), чтобы обе строки помещались целиком, на обеих платформах.
2. **«Серверы» больше не пустые.** Список заполняется из трёх источников:
   - серверы клиент-серверных баз вашего списка (как раньше);
   - серверы, для которых вы уже сохраняли порты (`server_ports.json` — мониторинг/диагностика);
   - адрес цели проверки — **всегда**, даже когда внешних источников нет: открыв окно на базе или мониторе, вы сразу видите текущий сервер в списке, он же выбран; поле остаётся редактируемым для ручного ввода.
   Если клиент-серверных баз в списке нет, но сервер вы вводите вручную и проверяете — он добавится в «Серверы» при следующем открытии (из сохранённых портов).

- WPF [`Views/NetworkDiagnosticsWindow.xaml`](Configuration%20Management/Views/NetworkDiagnosticsWindow.xaml) и Avalonia [`Views/NetworkDiagnosticsWindow.Avalonia.cs`](Configuration%20Management/Views/NetworkDiagnosticsWindow.Avalonia.cs) — панель команд в две строки, `MinWidth` 760;

- точки вызова [`ViewModels/MainViewModel.Tools.cs`](Configuration%20Management/ViewModels/MainViewModel.Tools.cs) и [`ViewModels/MainViewModel.Avalonia.Tools.cs`](Configuration%20Management/ViewModels/MainViewModel.Avalonia.Tools.cs) — передают объединённый список;
- локализация не менялась (использованы существующие ключи `Diagnostics.*`).

**Тесты.** Полный набор `dotnet test` зелёный (**1530**), кросс-сборка Linux (`dotnet build -p:BuildLinux=true`) без ошибок. Добавлены тесты: пустой внешний список → адрес цели присутствует в «Серверы» и выбран; дубликаты внешнего списка и цели снимаются, список отсортирован; объединение источников (базы + сохранённые порты + цель), битое хранилище не роняет список.

**Как проверить в 0.3.9.269.**

1. Откройте «Утилиты → Диагностика подключения» на клиент-серверной базе: поле «Серверы» не пусто (текущий сервер в списке и выбран), все кнопки видны и на второй строке.
2. Сузьте окно до минимума — кнопки остаются видимыми (обе строки помещаются).
3. У базы без клиент-серверных баз в списке: «Серверы» всё равно содержит адрес проверки; можно ввести сервер вручную — проверка работает как раньше, порт запомнится.
4. Повторите на Linux (Avalonia).
