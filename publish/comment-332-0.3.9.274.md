Исправлено в версии **0.3.9.274** (Windows/WPF и Linux/Avalonia).

**Что было.**

Если у базы в свойствах указать URL публикации с завершающим сегментом локали — например `https://host/base/ru_RU/` — то при открытии ссылки 1С показывала страницу с локалью, а в ряде случаев переход вообще не работал. Обрезка сегмента локали (исправление 0.3.9.234) была сделана только для «Перейти по ссылке»; при сохранении свойств базы URL сохранялся как введён.

**Как исправлено.**

Теперь обрезка выполняется в **единой точке при сохранении свойств базы**: поле «URL публикации» автоматически очищается от завершающего сегмента локали `ru_RU` / `en_US` — тихо, без диалогов и запросов, так же, как это делает штатный загрузчик 1С. Например, `https://host/base/ru_RU/` при сохранении превращается в `https://host/base/`.

Правка сделана в общем методе `ApplyTo`, который используют обе платформы (Windows/WPF и Linux/Avalonia), и опирается на тот же хелпер `OneCLauncher.StripWebLocaleSegment`, что и «Перейти по ссылке», — поведение согласовано везде.

Файлы:

- [`ViewModels/ConnectionSettingsViewModel.cs`](Configuration%20Management/ViewModels/ConnectionSettingsViewModel.cs:1294) — `ApplyTo`: `conn.WebUrl = OneCLauncher.StripWebLocaleSegment(WebUrl) ?? string.Empty;`.

**Тесты.** Полный набор `dotnet test` зелёный, кросс-сборка Linux (`dotnet build -p:BuildLinux=true`) без ошибок. Добавлен сквозной тест: база с `ConnectionType.WebServer` и `WebUrl = https://host/base/ru_RU/` → после `ApplyTo` URL становится `https://host/base/`; для файловой базы и базы на сервере 1С URL не изменяется. Существующие тесты хелпера (`WebLinkLocaleTests`) подтверждают, что «Перейти по ссылке» не сломано.

**Как проверить:**

1. Установите **0.3.9.274** ([релиз v0.3.9.274](https://github.com/sivatorov/ConfigurationManagement/releases/tag/v0.3.9.274)).
2. В свойствах базы (тип «Веб-сервер») укажите URL публикации `https://host/base/ru_RU/`, сохраните.
3. Откройте свойства снова — в поле URL хранится `https://host/base/` (без сегмента локали).
4. «Перейти по ссылке» открывает правильный адрес.
