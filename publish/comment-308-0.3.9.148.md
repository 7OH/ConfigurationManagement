Исправлено в версии **0.3.9.148** (Windows/WPF и Linux/Avalonia) — два замечания: «выбранная база отображается ключом, превью командной строки пустое» (14:37) и «перенесите галку "Скрывать окно скрипта" на строку с Интерпретатором» (14:39).

**1. Комбобокс «База для примера подстановок» снова показывает имя базы, превью заполняется.**
Причина была та же, что и в окне сравнения конфигураций: закрытый комбобокс рисует выбранный элемент до применения шаблона/пути отображения и показывает `ToString()` объекта. У `Infobase` нет переопределения `ToString()`, поэтому отображалось имя типа (`Configuration_Management.Models.Infobase`), похожее на «ключ». Правки:
- WPF ([`Views/ScriptScenarioEditWindow.xaml`](Configuration%20Management/Views/ScriptScenarioEditWindow.xaml)) — вместо `DisplayMemberPath`, задаваемого из code-behind, задан явный `ItemTemplate` (`<TextBlock Text="{Binding Name}"/>`);
- обе платформы — выбор первой базы переустанавливается после показа окна (`Loaded` в WPF, `Opened` в Avalonia, [`Views/ScriptScenarioEditWindow.xaml.cs`](Configuration%20Management/Views/ScriptScenarioEditWindow.xaml.cs) и [`Views/ScriptScenarioEditWindow.Avalonia.cs`](Configuration%20Management/Views/ScriptScenarioEditWindow.Avalonia.cs)): повторный `SelectedIndex` пересоздаёт контейнер с применённым шаблоном;
- Avalonia — проверен порядок `ItemsSource → ItemTemplate → SelectedIndex`.

Так как превью строится по выбранной базе, после исправления оно снова заполняется и меняется при выборе любой базы.

**2. Галка «Скрывать окно скрипта» перенесена в одну строку с «Интерпретатор».**
Комбобокс интерпретатора и галка теперь размещаются в одной строке (WPF — общий `Grid` с колонками «комбо» + «галка»; Avalonia — аналогичная строка), вертикально отцентрированы. Внизу окна отдельной строки больше нет — ничего не теряется.

Тесты: `dotnet test` полностью зелёный (670/670). Linux-сборка (`dotnet build -p:BuildLinux=true`) без ошибок.

**Как проверить.**
1. «Утилиты» → «Настройка сценариев» → «Изменить» (и «Изменить» из окна выбора скрипта F5) → комбобокс «База для примера подстановок»: закрытый элемент показывает **имя базы**, а не имя типа.
2. Выберите любую базу из списка — превью командной строки меняется и не пустое.
3. Галка «Скрывать окно скрипта» — на одной строке с «Интерпретатор» (обе платформы).
