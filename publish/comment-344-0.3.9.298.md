Исправлено в версии **0.3.9.298** (обе платформы — Windows/WPF и Linux/Avalonia, общий код хранилища).

Реализован первый из предложенных вами вариантов: файлы в `scripts/scenarios` теперь называются `<Имя>.<Id>.script.json`, например

`Calc.19fb08b20a2b434588e6d857479c50f0.script.json`

**Почему выбран вариант с Id в имени.** Хранилище работает по идентификатору сценария (`Get`/`Delete`/`Save` по `Id`) — Id в имени файла позволяет находить файл детерминированно и без индекса. При варианте «только имя» одинаковые имена перезаписывали бы друг друга, а переименование сценария требовало бы помнить исходное имя файла; здесь же смена имени просто меняет префикс, а суффикс-Id исключает коллизии.

**Что ещё сделано.**
- **Старые файлы** вида `<id>.script.json` продолжают читаться без изменений; при первом редактировании сценария файл автоматически переименовывается в новый формат (старый удаляется, дубликатов не остаётся).
- **Санитизация имени**: недопустимые символы (`:`, `/`, `\`, `*` и т.п.) заменяются на «_», кириллица сохраняется, длина обрезается до безопасной, зарезервированные имена устройств Windows (`CON`, `PRN`, `NUL`, `COM1…`, `LPT1…`) и скрытые файлы (ведущая точка) получают префикс «_».
- Одинаковые имена («Calc» и «Calc») — два разных файла, обе записи видны в списке.
- Сортировка списка по имени сохранена.

Пожалуйста, обновитесь до 0.3.9.298 и проверьте: откройте папку `scripts/scenarios` (видны читаемые имена), создайте/отредактируйте сценарий (имя файла обновится), переименуйте сценарий (старый файл исчезнет).
