Исправлено в версии **0.3.9.237** (Windows/WPF и Linux/Avalonia).

**Что было сломано.** После удаления пустой группы следующая синхронизация/импорт из 1С
(ibases.v8i) возвращала её обратно: группа-секция есть в файле, и импортёр создавал группу
заново, хотя пользователь её намеренно удалил. Базы при этом не возвращались — только пустые
группы.

**Причина.** Импорт (`EnsureGroups`/`CreateGroupWithParents` в `IbasesV8iImporter`) создаёт все
группы, которые встречает в файле, без учёта того, что пользователь удалил часть из них
вручную. Запрет на удаление непустых групп в приложении не давал подсказки импортёру:
удалённая группа всегда «пустая или отсутствует», поэтому ничто не мешало создать её снова.

**Как исправлено.**

- Введён персистентный список полных путей удалённых пользователем пустых групп — читаемый
  JSON-файл **`deleted_groups.json`** рядом с настройками приложения
  ([`DeletedGroupPathsStore`](Configuration Management/Services/DeletedGroupPathsStore.cs),
  паттерн `custom_config_types.json`, атомарная запись).
- При удалении пустой группы (обе платформы) её полный путь запоминается в этом списке.
- При импорте пути из списка пропускаются, **пока под ними нет баз из файла**
  (`HasBasesUnderPath`): если в группе снова появились базы — группа нужна и пересоздаётся,
  базы импортируются как раньше. Потомки под удалённой пустой веткой без баз не создаются
  (иначе «осиротели» бы). Непустые группы и обычные группы файла импортируются без изменений.
- Список передаётся через `IIbasesSyncService.Import` во все точки синхронизации (ручной
  импорт, автосинхронизация, разовый импорт).
- **Сброс**: чтобы вернуть группы, достаточно удалить файл `deleted_groups.json` (или очистить
  его содержимое) — при следующем импорте группы начнут создаваться как раньше.
- Юнит-тесты `IbasesV8iImporterTombstoneTests`: удалённый путь не пересоздаётся; путь с новыми
  базами создаётся; непустая группа с тем же путём не трогается; вложенная удалённая ветка без
  баз не создаётся; регрессия обычного импорта. `DeletedGroupPathsStoreTests`: Add/Load,
  идемпотентность (без дублей, регистронезависимо), Clear удаляет файл, отсутствие файла →
  пустой список.

**Как проверить.**

1. Установите версию **0.3.9.237** (Windows или Linux).
2. Создайте пустую группу, затем удалите её (контекстное меню → «Удалить»).
3. Выполните импорт/синхронизацию с `ibases.v8i` (например, Настройки → Базы → «Импортировать
   из ibases.v8i» или повторную синхронизацию) — удалённая пустая группа **не** возвращается.
4. Добавьте в эту группу базу (например, через стандартный стартер 1С) и повторите импорт —
   группа пересоздастся вместе с базой.
5. Удалите файл `deleted_groups.json` рядом с настройками приложения и повторите импорт:
   группы из файла снова создаются.
