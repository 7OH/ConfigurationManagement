# v0.3.12.23 — Исправления по issues #371, #370, #367, #366, #365, #361, #352

Windows/WPF и Linux/Avalonia.

## Исправлено

- **Парсинг версии из HTML-страницы каталога обновлений переписан
  ([#371](https://github.com/sivatorov/ConfigurationManagement/issues/371))** — версия
  теперь распознаётся, даже когда она указана в query ссылки или в атрибутах
  `data-ver`/`data-version`; приоритет отдаётся таблице версий. Проверка обновлений
  УПП (`Enterprise13`) снова находит актуальную версию.
- **Копия задания в «Заданиях по расписанию» больше не сохраняется сразу
  ([#370](https://github.com/sivatorov/ConfigurationManagement/issues/370))** — после
  «Скопировать» открывается окно редактирования копии, заполненное данными исходной
  строки; запись в список происходит только при подтверждении сохранения.
- **Диагностика ошибки «Загрузить» в «Обозревателе метаданных» улучшена
  ([#365](https://github.com/sivatorov/ConfigurationManagement/issues/365))** —
  реальная причина сбоя выводится в диалоге и тултипе, а также пишется в журнал.
- **Поиск установленных версий платформы 1С на всех логических дисках
  ([#361](https://github.com/sivatorov/ConfigurationManagement/issues/361))** —
  сканируются каталоги `Program Files` и `Program Files (x86)` на всех дисках, а не
  только на `C:`; версии, установленные на другом диске, снова помечаются
  «Установлена» в окне «Обновление платформы 1С» и не предлагаются как обновление.
- **Скачивание цепочки обновлений: оригинальные имена файлов и геометрия окна
  ([#352](https://github.com/sivatorov/ConfigurationManagement/issues/352))** —
  файлы цепочки сохраняются с оригинальными именами дистрибутивов (как при одиночном
  скачивании, с сохранением `.download`-механики и докачки); окно цепочки больше
  не выходит за пределы рабочей области; кнопки «Выбрать»/«Открыть» увеличены
  и больше не обрезаются снизу.

## Добавлено

- **Задание «Проверка наличия обновления для конфигурации»: опция «Уведомлять об
  отсутствии обновлений»
  ([#367](https://github.com/sivatorov/ConfigurationManagement/issues/367))** —
  при отсутствии новых версий уведомление не выдаётся.
- **Задание «Проверка наличия версии платформы»: опция «Уведомлять об отсутствии
  обновлений» и повторение в течение дня
  ([#366](https://github.com/sivatorov/ConfigurationManagement/issues/366))** —
  добавлена настройка интервала повтора (значение + единица измерения:
  секунды/минуты/часы), задание может выполняться несколько раз в день. При
  отсутствии обновлений уведомление подавляется.
