Часть 1 из 2, исправлено в версии **0.3.9.283** (Windows/WPF и Linux/Avalonia).

**Что сделано по замечаниям:**

1. **Поле «Сегмент адреса» переименовано в «Имя конфигурации».** В списке типовых конфигураций и в форме редактирования колонка теперь называется «Имя конфигурации» — в ней имя как в самой конфигурации 1С (например «БухгалтерияПредприятия»). Подсказка поясняет: значение используется для сопоставления данных о конфигурации, в адрес обновлений не попадает. Сам сегмент адреса остался отдельным полем редактора (он нужен для построения URL).

2. **Корректные значения для поставляемых данных** ([`Services/BuiltInConfigTypes.cs`](Configuration%20Management/Services/BuiltInConfigTypes.cs)):

   | Конфигурация | Имя конфигурации |
   |---|---|
   | БП | БухгалтерияПредприятия |
   | ЗУП | ЗарплатаИУправлениеПерсоналом |
   | УТ | УправлениеТорговлей |
   | КА | КомплекснаяАвтоматизация |
   | Розница | Retail |
   | ERP | УправлениеПредприятием |
   | БГУ | БухгалтерияГосударственногоУчреждения |

   Редакции дополнены по вашему списку: УТ — 11 и 10.3; КА — 2.5, 2.0, 1.1, 1.0; Розница — 3.0 и 2.3.

3. **В адрес не попадает.** Новое поле `ConfigName` добавлено в модель [`OneCConfigType`](Configuration%20Management/Models/OneCConfigType.cs) отдельно от `UrlCode`/`Nick` и не участвует в построении адреса — проверено тестом.

4. **Поиск** по списку конфигураций теперь ищет и по «Имени конфигурации» ([`ConfigTypesFilter.cs`](Configuration%20Management/ViewModels/ConfigTypesFilter.cs)).

Старые файлы пользовательских конфигураций (`custom_config_types.json`) без нового поля читаются без ошибок — поле просто пустое.

**Тесты.** Добавлены [`BuiltInConfigTypesTests.cs`](ConfigurationManagement.Tests/BuiltInConfigTypesTests.cs): значения `ConfigName` по списку, непустые у всех типовых, независимость от `EffectiveUrlCode`, редакции. Полный набор `dotnet test` зелёный (1579), кросс-сборка Linux (`dotnet build -p:BuildLinux=true`) без ошибок.

**Как проверить:**

1. Установите **0.3.9.283** ([релиз v0.3.9.283](https://github.com/sivatorov/ConfigurationManagement/releases/tag/v0.3.9.283)).
2. Откройте «Типовые конфигурации» (Утилиты): в колонке «Имя конфигурации» должны стоять значения из таблицы выше.
3. Откройте строку на правку: поле «Имя конфигурации» есть в форме и сохраняется.
