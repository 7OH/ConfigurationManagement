Исправлено в версии **0.3.12.6** (Windows и Linux), issue #352 остаётся открытым:

1. **Имена файлов обновления сохраняют оригинальное имя** — файл сохраняется как «<Имя>_<версия>_<оригинал>» (например `УТ_11.5.26.118_Trade_11_5_26_118_updsetup.cf`), чтобы «полный дистрибутив» и «дистрибутив обновления» различались и не перезаписывали друг друга.

2. **Папка одиночного скачивания запоминается отдельно от папки цепочки** («что для полной версии, что для цепочки») — новая настройка `UpdateDistributionFolder`; диалог сохранения предлагает её же.

3. **Окно проверки обновлений подхватывает активную загрузку при переоткрытии** — клик по индикатору на главном окне возвращает окно с реальным прогрессом уже идущей закачки для этой ИБ.

Показ оригинального имени в Title/индикаторе отложен до отдельной задачи — чтобы не ломать выбор окна из индикатора (v0.3.12.5).

Тесты: `dotnet test` — **2302** (новые `UpdateDownloadNamingTests`, +4); сборки WPF и Linux без ошибок. Ассеты: exe, zip, linux-x64, deb, SHA256SUMS.txt — в релизе v0.3.12.6.
