Исправлено в версии **0.3.9.267** (Windows/WPF и Linux/Avalonia).

**Что сделано по вашим замечаниям к окну «Связать с конфигурацией».**

1. **Компоновка: больше места названию конфигурации.** Поле выбора конфигурации занимает всю ширину окна; кнопки «Список типовых конфигураций» и «Определить версию» — в одной строке, а надпись о текущих свойствах базы перенесена на отдельную строку под кнопками (она больше никого не ужимает и сама переносится по всей ширине). Окно расширено (WPF 720/600, Avalonia 700/580) — длинные названия не обрезаются при стандартной ширине.
2. **Стало понятно, по какому полю идёт поиск.** У кнопки «Определить версию» теперь есть ToolTip, а под кнопками — постоянная подсказка: поиск идёт (1) по точному имени конфигурации базы (вкладка «Платформа»), затем (2) по сегменту адреса обновлений, затем (3) по вхождению имени. В строке результата после «Определить версию» дополнительно показывается причина совпадения — «по точному имени» / «по сегменту адреса обновлений» / «по вхождению имени». Логика сопоставления (`ConfigTypeMatcher`) не менялась — только добавился понятный вывод причины (приоритет «точное имя → сегмент → вхождение» сохранён, чтобы не сломать автоопределение каталога релизов).
3. **В списке выбора видно, какая запись типовая, а какая пользовательская.** Каждая строка выпадающего списка помечена: ★ типовая, «пользовательская» — добавленная вами, ✎★ — пользовательская копия, которая перекрывает типовую (правка встроенной записи из 0.3.9.265). Плюс ToolTip на строке с именем, кодом и сегментом адреса. Если вы добавили нетиповую запись ЗУП с сегментом «ЗарплатаИУправлениеПерсоналом» — она в списке, помечена как пользовательская, и видно, какая именно выбрана. Ваш случай (нашлась типовая): имя конфигурации базы точно совпало с типовой ЗУП «Зарплата и управление персоналом» (приоритет имени выше сегмента) — теперь это явно видно по причине в строке результата и по метке выбранной записи.
4. **Дубль «Основная» в списках учёток ИТС.** Исправлен в **0.3.9.261** (#333): если в справочнике есть реальная запись «Основная» — виртуальный пункт не добавляется. Окно «Связать с конфигурацией» списки учёток не использует, дубликатов там нет.

**Как проверить в 0.3.9.267.**

1. Правый клик по базе → «Связать с конфигурацией»: название конфигурации не обрезается, кнопки и надпись о свойствах базы — на своих строках.
2. Наведите на кнопку «Определить версию» — подсказка о критериях поиска; нажмите её — в зелёной строке появится причина («по точному имени» и т.п.).
3. Раскройте список «Конфигурация» — у строк метки «★ типовая» / «пользовательская» / «✎★ пользовательская копия»; наведите на строку — справка с кодом и сегментом адреса.
