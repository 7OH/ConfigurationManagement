Сделано в версии **0.3.9.154** (Windows/WPF и Linux/Avalonia) — для баз вида «Веб-сервер» в колонке «Сервер/База» теперь отображается URL публикации (`Connection.WebUrl`), а не пустое значение.

**Причина.** Свойство `ServerDatabaseDisplay` для типа «Веб-сервер» уходило в общую ветку клиент-серверных баз и возвращало имя базы (а если оно не задано — пустоту), поэтому в списке колонка оставалась пустой. Теперь для `ConnectionType.WebServer` возвращается непустой `WebUrl`; при отсутствии URL — имя базы или «—».

**Что изменено.** Единая точка отображения [`Models/Infobase.cs`](Configuration%20Management/Models/Infobase.cs) — `ServerDatabaseDisplay`, поэтому URL показывается сразу везде: в колонке «Сервер/База» списка баз (WPF и Avalonia) и в карточке базы. Файловые и клиент-серверные базы отображаются как раньше. Добавлены тесты `InfobaseDisplayTests`: WebServer + WebUrl → URL; WebServer без WebUrl → имя базы/«—»; File → путь; ClientServer → `сервер\база`.

**Как проверить.** Установите версию **0.3.9.154**, создайте или импортируйте веб-серверную базу с WebUrl (например `http://host/name`) — в списке колонка «Сервер/База» показывает URL, в карточке базы — тоже.
