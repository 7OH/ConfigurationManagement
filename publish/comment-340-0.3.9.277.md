Исправлено в версии **0.3.9.277** (Windows/WPF).

**Что было.**

После мультивыделения (Ctrl или Shift) правый клик открывает контекстное меню, а клик по другой строке «для снятия выделения» не работал как ожидалось: меню исчезало, но выбор строки и снятие мультивыделения не применялись.

**Причина.**

Пока контекстное меню открыто, WPF держит захват мыши в попапе меню: событие клика по строке дерева уходит в попап и только закрывает меню («проглатывается»). Обычная логика клика — `OnInfobaseTree_PreviewMouseLeftButtonDown` (снятие мультивыделения `ClearBatchSelection` + выбор строки `ApplySelection`) — при этом не выполнялась, поэтому строка не выбиралась, а пакетная подсветка оставалась «висеть».

**Как исправлено.**

При закрытии контекстного меню дерева (`ContextMenu.Closed`, класс-обработчик уже ведёт реестр открытых меню для issue #261) добавляется проверка: если меню закрылось кликом левой кнопки по строке базы — выбор применяется повторно. Строка под курсором определяется hit-тестом по координате мыши, мультивыделение снимается и строка выбирается отложенно (после освобождения захвата попапа).

Случаи закрытия выбором пункта меню (мышь в этот момент над пунктом) и закрытия по ESC / программно (кнопка мыши не нажата) отсекаются проверками — там выбор не трогается.

Файл: [`Views/MainWindow.Hotkeys.cs`](Configuration%20Management/Views/MainWindow.Hotkeys.cs) — `OnContextMenuClosed` вызывает новый метод `TryApplyTreeClickAfterMenuClosed`.

**Тесты.**

Полный набор `dotnet test` зелёный (1553), кросс-сборка Linux (`dotnet build -p:BuildLinux=true`) без ошибок. Само поведение зависит от оконного стека WPF и юнит-тестами не покрывается.

**Как проверить:**

1. Установите **0.3.9.277** ([релиз v0.3.9.277](https://github.com/sivatorov/ConfigurationManagement/releases/tag/v0.3.9.277)).
2. Выделите несколько баз (Ctrl или Shift), нажмите правую кнопку — откроется контекстное меню.
3. Кликните левой по другой строке: меню закрывается, мультивыделение снимается, выбранная строка подсвечивается как текущая.
4. Проверьте, что выбор пункта меню и закрытие по ESC не меняют выделение.
