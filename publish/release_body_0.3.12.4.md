# v0.3.12.4 — Оценка оставшегося времени загрузок (issue #360)

Windows/WPF и Linux/Avalonia.

## Добавлено

- **Оценка оставшегося времени загрузок (issue #360)** — у полос прогресса
  теперь показывается, сколько осталось до окончания: «00:25»/«16:13» (mm:ss)
  до часа, «2:15:18» (h:mm:ss) свыше часа. Оценка появляется после первых
  секунд загрузки (пока данных мало — просто проценты) и сглаживается по
  скорости отчётов прогресса:
  - **индикатор фоновых загрузок главного окна** — время рядом с агрегированной
    полосой прогресса; для нескольких одновременных загрузок показывается
    максимальная оценка (когда завершатся все);
  - **окно проверки обновлений** — одиночное скачивание («45 % · 16:13») и
    загрузка цепочки обновлений (оценка агрегированного прогресса цепочки);
  - **окно «Скачивание версии платформы 1С»** — время после процентов;
  - **окно «Обновление платформы 1С»** — время под общей полосой прогресса.
- **`Services/DownloadEta.cs`** — форматирование оценки и трекер
  `DownloadEtaTracker` (сглаженная скорость, порог показа 2 с, часы
  инжектируются — тесты детерминированы). Записи менеджера фоновых загрузок
  обогащены свойством `ActiveDownload.EstimatedRemaining`.

## Тесты

Полный набор `dotnet test` зелёный (**2298**); сборка решения (`dotnet build`) и
кросс-сборка Linux (`dotnet build -p:ForceLinux=true`) без ошибок.
