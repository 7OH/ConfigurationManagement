Исправлено в версии **0.3.9.114** (Windows/WPF и Linux/Avalonia).

**Что было не так.**

Если набирать набор «для выделенных» Ctrl+кликами (2–3 базы), а затем щёлкнуть
правой кнопкой по строке, из набора пропадала первая база — контекстное меню
показывало меньше баз, чем было помечено. Shift-диапазон работал корректно.

**Причина.**

- Linux/Avalonia — [`Controls/LeveledTreeView.Avalonia.cs`](Configuration%20Management/Controls/LeveledTreeView.Avalonia.cs):
  ветка Ctrl в `OnRowPointerPressed` не проверяла нажатую кнопку. После серии
  Ctrl+кликов пользователь жмёт правую кнопку (часто не отпуская Ctrl) по строке —
  срабатывал повторный `ToggleBatchSelection(rowBase, "Ctrl")`, и строка из набора
  снималась (toggle), хотя ожидалось просто открытие контекстного меню.
- Windows/WPF — [`Views/MainWindow.Events.cs`](Configuration%20Management/Views/MainWindow.Events.cs):
  обработчик правого клика уже не трогал набор; поведение зафиксировано явно
  (только `IsSelected`/`SelectedInfobase`, без `ToggleBatchSelection`/`ClearBatchSelection`).

**Как исправлено.**

Правый клик теперь меняет только основное выделение под курсором (`IsSelected`/
`SelectedInfobase`), а набор «для выделенных» сохраняется до открытия меню:

- Linux/Avalonia — ветка Ctrl требует левую кнопку
  (`point.Properties.IsLeftButtonPressed`); правый клик с любыми модификаторами идёт
  только в `SelectRow` и набор не трогает. Shift-ветка и снятие набора обычным левым
  кликом без модификаторов не изменены.
- Windows/WPF — `OnInfobaseTree_PreviewMouseRightButtonDown` по-прежнему ставит только
  основное выделение; в код добавлен комментарий, фиксирующий, что модификаторы
  Ctrl/Shift при правом клике намеренно игнорируются (они влияют на мультивыделение
  только при левом клике).

Заголовок и видимость блока «Для выделенных (N)…» пересчитываются по фактическому
набору при каждом открытии меню (WPF — `OnBaseContextMenu_Opened`, Avalonia —
`menu.Opening`), поэтому после исправления в меню всегда видны все помеченные базы.

**Как проверить.**

1. Ctrl+клик по 2–3 базам → набор подсвечивается вторичным фоном.
2. Правый клик по любой строке (в т.ч. по строке из набора, не отпуская Ctrl) →
   контекстное меню показывает блок «Для выделенных (N)» с полным числом баз.
3. Ctrl+клик по уже помеченной строке по-прежнему снимает её (точечный toggle работает).
4. Shift-диапазон и обычный клик (сброс набора) не изменились.

Тесты: `dotnet test` — 399 зелёных; `dotnet build -p:BuildLinux=true` — без ошибок.
