Исправлено в версии **0.3.9.71** (Windows/WPF и Linux/Avalonia).

**Что было не так.**

Ваша критика по пунктам была справедливой: «Блокировка приложения» при уже заданном
пароле немедленно открывала модальное окно разблокировки, которое нельзя было закрыть
без ввода пароля, а после ввода ничего не блокировалось. Состояния блокировки как
такового не существовало — поэтому «блокировка не блокирует ничего», «разблокировка
ничего не значит», а повторный вызов снова показывал разблокировку. Плюс фокус в поле
ввода ставился ненадёжно.

**Как работает теперь.**

1. **Блокировка — постоянное состояние сеанса.** Пункт меню «Блокировка приложения»
   (Утилиты) при заданном пароле сразу блокирует приложение: клиентская область
   закрывается затемнённым оверлеем «Приложение заблокировано», весь ввод в окно
   (мышь и клавиатура, включая горячие клавиши) не проходит.
2. **Окно ввода пароля снова закрываемое** — крестик, «Отмена» и Esc работают:
   закрытие окна **не снимает** блокировку. Оверлей остаётся, и любое взаимодействие
   с окном приложения (клик, нажатие клавиши) снова открывает окно ввода пароля.
   Блокировка снимается **только** вводом верного пароля.
3. **Первый вызов** (пароль ещё не задан) — как прежде: окно установки пароля,
   отмена = блокировка не включается; после сохранения пароля приложение блокируется.
4. **Повторный вызов** при активной блокировке просто показывает окно ввода пароля.
5. **Фокус в поле пароля** ставится сразу при открытии окна и дублируется после
   показа, чтобы курсор гарантированно стоял в поле (Windows и Linux).
6. Пока идёт блокировка, на Windows снимаются горячие клавиши окна, на Linux —
   KeyBindings и клавиатура главного окна: команды нельзя вызвать в обход блокировки.

**Как проверить:**

1. Установите версию **0.3.9.74** (файлы — на странице релиза
   [v0.3.9.74](https://github.com/sivatorov/ConfigurationManagement/releases/tag/v0.3.9.74)).
2. Меню «Утилиты» → «Блокировка приложения»: задайте пароль → приложение блокируется,
   появляется оверлей и окно ввода пароля.
3. Закройте окно ввода («Отмена», крестик или Esc) — интерфейс остаётся заблокирован;
   клик по оверлею снова открывает окно ввода.
4. Введите верный пароль — блокировка снята, интерфейс доступен.
5. Введите неверный — предупреждение, блокировка остаётся.
