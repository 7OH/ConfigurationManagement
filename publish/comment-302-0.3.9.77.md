Исправлено в версии **0.3.9.77** (Windows/WPF и Linux/Avalonia).

**Причина.** Все версии приложения скачивались в один и тот же временный файл
`ConfigurationManagement.new.exe` в каталоге `%TEMP%\ConfigurationManagement\update`.
При следующей проверке обновлений остаток загрузки **предыдущей** версии
принимался за «докачку» новой: загрузчик запрашивал по HTTP Range только
недостающий «хвост» (килобайты — размеры соседних сборок отличаются меньше чем
на процент), поэтому скачивание «завершалось мгновенно», а устанавливался
гибрид из старого начала и нового конца файла. Повреждённая сборка не проходит
проверку встроенного хоста .NET — отсюда требование «установить .NET», хотя он
стоит. Ручная очистка временных файлов помогала, потому что заставляла скачать
файл целиком. Остатки появлялись после обрыва связи, закрытия диалога обновления
без применения и сбоя замены exe помощником.

**Что сделано.**

1. **Временный файл носит версию в имени** (`ConfigurationManagement.<версия>.new.exe`)
   — остаток чужой версии физически не может быть принят за докачку. Остатки
   прошлых версий в каталоге обновлений удаляются при новой загрузке.
2. **Докачка привязана к ETag ассета GitHub** (метка идентичности содержимого,
   хранится рядом с файлом): не совпал — загрузка начинается с нуля. Относится
   и к однопоточной докачке, и к частям многопоточной.
3. **Файл принимается только точного размера** — ожидаемого из GitHub API
   (поле `size` ассета) либо заявленного сервером; прежняя проверка «не меньше»
   пропускала обрезанные и «удлинённые» гибриды. Если размер с сервера не
   совпал с API — загрузка даже не начинается.
4. **Гигиена:** скачанный файл удаляется при закрытии диалога без применения
   обновления и при финальном сбое помощника замены (раньше оставался в %TEMP%).

**Как проверить:**

1. Установите версию **0.3.9.77** и ниже (файлы на странице релиза
   [v0.3.9.78](https://github.com/sivatorov/ConfigurationManagement/releases/tag/v0.3.9.78)).
2. Запустите обновление на 0.3.9.78: прогресс должен идти честно (не мгновенно),
   после перезапуска в заголовке — новая версия без требований установить .NET.
3. Повторите проверку обновлений на актуальной версии — сообщение «у вас
   актуальная версия», без повторных скачиваний.
4. При желании: закройте диалог обновления на середине загрузки, запустите
   снова — загрузка начнётся заново (остаток без совпадения ETag не принимается).
