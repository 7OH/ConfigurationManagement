# Управление конфигурациями 1С — v0.3.9.270

Серия из **семнадцати улучшений** (цикл 0.3.9.254–0.3.9.270) по собственной дорожной
карте проекта, сгруппированных в восемь пакетов: точечные исправления окон настроек,
подключения и заголовков групп (П1), синхронизация с `ibases.v8i` (П2),
горизонтальный скролл колонок (П3), автообновление и скачивание платформы 1С (П4),
справочник учётных данных ИТС (П5), выбор сервера и диагностика подключения (П6),
типовые конфигурации, связывание с конфигурацией и проверка обновлений (П7), порты
rac/RAS в мониторе серверов и импорте из кластера (П8). Каждое улучшение реализовано
на **обеих платформах** (Windows/WPF и Linux/Avalonia) с юнит-тестами.

## Изменения

### П1. Точечные исправления (0.3.9.254–256)

1. **0.3.9.254 — [#337](https://github.com/sivatorov/ConfigurationManagement/issues/337)**
   — падение при открытии окна «Настройки» (`XamlParseException`, не найден стиль
   `OutlineButtonStyle` у кнопки «Управлять» справочника ИТС с 0.3.9.247): стиль объявлен
   в ресурсах окна, добавлен тест защиты от регрессии по всем `{StaticResource}`.
2. **0.3.9.255 — [#336](https://github.com/sivatorov/ConfigurationManagement/issues/336)**
   — количество групп: для групп с вложенными подгруппами заголовок показывает
   «(подгруппы / базы)», например «Группа с базами (4 / 28)»; вид «(M)» для групп без
   подгрупп не изменился.
3. **0.3.9.256 — [#325](https://github.com/sivatorov/ConfigurationManagement/issues/325)**
   — окно подключения: подпись «Конфигурация» выровнена напротив верхнего поля ввода
   (имени конфигурации), а не к верху группы; кнопка «Определить» и подсказка — на
   отдельной строке.

### П2. Синхронизация и дерево баз (0.3.9.257, 263–264)

4. **0.3.9.257 — [#327](https://github.com/sivatorov/ConfigurationManagement/issues/327)**
   — полная двусторонняя синхронизация удаляет из `ibases.v8i` секции-группы, которых
   больше нет в приложении (только пустые, вложенные — повторным проходом); сводка
   показывает «удалено групп: N».
5. **0.3.9.263 — [#313](https://github.com/sivatorov/ConfigurationManagement/issues/313)**
   — «Для выделенных»: по предложению пользователя первый Ctrl-клик добавляет в набор
   и «текущую» строку, и целевую (как в проводнике); правило секций закреплений
   соблюдается.
6. **0.3.9.264 — [#326](https://github.com/sivatorov/ConfigurationManagement/issues/326)**
   — мультивыделение в закреплениях: Shift/Ctrl-выбор больше не «уходит» в общий список —
   порядок закреплённой секции строится по данным узла, подсветка строк зависит от
   секции набора.

### П3. Горизонтальный скролл колонок (0.3.9.258)

7. **0.3.9.258 — [#309](https://github.com/sivatorov/ConfigurationManagement/issues/309)**
   — горизонтальная прокрутка списка баз, седьмая попытка: при виртуализации жёсткий
   минимум ширины дублируется на корневые Grid строк, замер контента расширен до 12 строк,
   добавлен инструментальный лог `CM_COLUMNS` для следующей итерации; последние колонки
   достижимы при любом масштабе.

### П4. Обновление и скачивание платформы (0.3.9.259–260)

8. **0.3.9.259 — [#330](https://github.com/sivatorov/ConfigurationManagement/issues/330)**
   — скачивание платформы: автопрокрутка журнала перенесена в UI-поток — устранено
   падение при открытии окна.
9. **0.3.9.260 — [#334](https://github.com/sivatorov/ConfigurationManagement/issues/334)**
   — обновление платформы: та же автопрокрутка журнала через UI-поток — падение при
   проверке обновлений устранено; пустой ответ портала 1С показывается как понятная
   ошибка сети.

### П5. Учётные данные ИТС (0.3.9.261)

10. **0.3.9.261 — [#333](https://github.com/sivatorov/ConfigurationManagement/issues/333)**
    — падение окна «Учётные данные ИТС» из-за TwoWay-привязки к read-only свойству
    `IsPrimary` (исправлено `Mode=OneWay`); дубль «Основная» в списках выбора устранён —
    виртуальный пункт не добавляется, если в справочнике есть запись «Основная».

### П6. Выбор сервера и диагностика подключения (0.3.9.262, 269)

11. **0.3.9.262 — [#305](https://github.com/sivatorov/ConfigurationManagement/issues/305)**
    — создание серверной базы: отключён автоподбор TextSearch у редактируемого ComboBox —
    выбор из списка подставляется целиком, ручной ввод (в т.ч. «localhost») не перебивается.
12. **0.3.9.269 — [#335](https://github.com/sivatorov/ConfigurationManagement/issues/335)**
    — «Диагностика подключения»: кнопки перенесены на вторую строку — видны при любой
    ширине окна (минимальная ширина увеличена до 760); список «Серверы» гарантированно
    содержит адрес цели проверки, даже когда внешних источников нет.

### П7. Типовые конфигурации, связь и проверка обновлений (0.3.9.265–268)

13. **0.3.9.265 — [#321](https://github.com/sivatorov/ConfigurationManagement/issues/321)**
    — окно типовых конфигураций (часть 1): правка встроенной записи больше не создаёт
    дубль строки (единое правило `MergeAll`), добавленные редакции видны сразу, окно
    редактора увеличено и подгоняется под экран.
14. **0.3.9.266 — [#321](https://github.com/sivatorov/ConfigurationManagement/issues/321)**
    — окно типовых конфигураций (часть 2): поле поиска по списку, более широкое окно,
    подсветка перекрытия типовой пользовательской копией, пояснение «Сегмент адреса
    (ник)», понятная колонка учётной записи.
15. **0.3.9.267 — [#322](https://github.com/sivatorov/ConfigurationManagement/issues/322)**
    — «Связать с конфигурацией»: поле выбора занимает всю ширину окна, добавлены
    подсказки о критериях автоопределения с причиной совпадения, происхождение записи
    помечено ★ / «пользовательская» / ✎★.
16. **0.3.9.268 — [#323](https://github.com/sivatorov/ConfigurationManagement/issues/323)**
    — «Проверка обновлений»: адрес каталога релизов стал кликабельной ссылкой
    (открывается через единый хелпер `OneCLauncher.OpenUrl`), неактивной при невалидном
    адресе.

### П8. Порты rac/RAS (0.3.9.270)

17. **0.3.9.270 — [#324](https://github.com/sivatorov/ConfigurationManagement/issues/324)**
    — монитор «Серверы 1С» и «Импорт из кластера»: порт можно указать прямо в адресе как
    `host:порт` (например `localhost:27545`) — порт из адреса имеет приоритет над полем
    «Порт»; сообщение «кластеры не найдены» объясняет, какой порт указывать (1540 —
    агент, 1541 — порт кластера, не нужен; 1545 — RAS); подсказки в окнах обновлены;
    новый хелпер `RacConnectionAddress` с тестами разбора (включая IPv6).

### Подтверждено пользователем

- **#328 — запуск базы по Enter** подтверждён пользователем (работает, без изменений в
  этой версии): фикс 0.3.9.241 остаётся в силе.
