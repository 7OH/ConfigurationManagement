## Управление конфигурациями 1С — v0.3.9.78

Пакет из четырёх исправлений по вопросам обратной связи (#294, #300, #302, #303).

### Блокировка приложения (#294) — 0.3.9.75

- **Смена пароля**: новый пункт «Сменить пароль блокировки» в меню «Утилиты» —
  текущий пароль, новый, повтор; пароль больше не «одноразовый».
- **Блокировка переживает перезапуск**: состояние сохраняется в настройках;
  закрытое из трея заблокированное приложение при следующем запуске открывается
  с запросом пароля.
- **Новый порядок блокировки**: после включения окно сворачивается в трей и не
  мешает работать; пароль запрашивается при попытке открыть окно (трей, вторая
  копия, запуск после перезапуска); при закрытии запроса без верного пароля окно
  сворачивается обратно. Снятие — только верным паролем.

### «Лишние значки» на Linux (#300) — 0.3.9.76

- Причина была не в строках списка: плашки правой панели «★ Избранное» и
  «📌 Закреплено» оставались видимыми при свёрнутых подробностях и висели над
  кнопками запуска. Теперь они показываются вместе с подробностями панели —
  как в Windows-версии. Прежние исправления сетки строки (0.3.9.69, 0.3.9.73)
  сохранены.

### Скачивание обновления (#302) — 0.3.9.77

- Устранено «мгновенное» скачивание с последующим требованием установить .NET:
  остаток загрузки предыдущей версии больше не принимается за докачку новой.
  Временный файл носит версию в имени, докачка разрешена только при совпадении
  ETag ассета, файл принимается точного размера (из GitHub API), temp очищается
  при закрытии диалога без применения и при сбое помощника.

### Масштаб строк списка (#303) — 0.3.9.78

- Настройка шрифта теперь влияет и на содержимое строк списка: область
  «Список баз»/«По умолчанию» масштабирует названия, ячейки, теги и группы
  пропорционально.
- **Ctrl + колесо мыши** над списком меняет масштаб строк.
- Горячие клавиши **Ctrl++ / Ctrl+- / Ctrl+0** (настраиваются в «Настройки →
  Клавиши»), масштаб сохраняется между запусками (0.5–3.0).
- «Применить» на вкладке шрифта сохраняет настройки сразу, без закрытия окна.

- `ConfigurationManagement` — Linux x64, single-file, самодостаточная сборка.
