Исправлено в версии **0.3.9.287** (Windows/WPF и Linux/Avalonia).

**Что было:** «Для входа на portal.1c.ru не задан логин» + пустой ответ каталога платформы в окне «Обновление платформы 1С» — выбранная учётная запись ИТС не доходила до [`GetCredentials()`](Configuration%20Management/Services/OneCUpdatesService.cs), а при отсутствии настроенных учётных данных служба возвращала голый NetworkError вместо понятного сообщения.

**Как исправлено** ([`OneCUpdatesService.cs`](Configuration%20Management/Services/OneCUpdatesService.cs)):

1. **Учётная запись ИТС доходит до `GetCredentials()`.** Выбор учётной записи из настроек/справочника проверен по всей цепочке; после фикса #333 пункт в списках выбора отображается именем, а не ключом, поэтому выбирается именно та запись, которую видит пользователь.
2. **Понятное сообщение вместо голой ошибки.** При отсутствии настроенных учётных данных службы показывают явное сообщение «Требуется вход на сайт 1С» вместо технического NetworkError.
3. **Заодно (общее с #323):** 302 без заголовка Location от releases.1c.ru теперь распознаётся как «требуется авторизация» — выполняется программный вход на portal.1c.ru (один раз за сессию службы) и повтор исходного запроса с сохранёнными cookie; если вход невозможен — понятная ошибка «Нет доступа к сайту 1С: требуется вход… Проверьте учётные данные ИТС» (`Updates.AuthRequired`).

**Тесты.** [`UpdateCheckCatalogTests`](ConfigurationManagement.Tests/UpdateCheckCatalogTests.cs) дополнены: 302 без Location → `AuthRequired`; 302 без Location → вход на portal.1c.ru → повторный запрос каталога → найдена новая версия; зелёный путь 200 с HTML. Полный набор `dotnet test` зелёный (1591), кросс-сборка Linux (`dotnet build -p:BuildLinux=true`) без ошибок.

**Как проверить:**

1. Установите **0.3.9.287** ([релиз v0.3.9.287](https://github.com/sivatorov/ConfigurationManagement/releases/tag/v0.3.9.287)).
2. В окне «Обновление платформы 1С» при отсутствии настроенных учётных данных ИТС должно появиться понятное сообщение «Требуется вход на сайт 1С», а не голый NetworkError.
3. Настройте учётные данные ИТС (Настройки → Учётные данные ИТС или Утилиты → Информация → Учетные данные ИТС) и повторите проверку обновлений платформы — она должна завершиться либо успешным результатом (автоматический вход на portal.1c.ru), либо понятной ошибкой авторизации.
