Реализовано в версии **0.3.12.5** (Windows/WPF и Linux/Avalonia).

**Что сделано.** Клик по тексту индикатора фоновых загрузок в нижней строке
главного окна теперь открывает правильное окно:

- если активные скачивания идут из **разных окон** — над индикатором всплывает
  небольшое всплывающее меню (пункты вида «окно: файл (45 %)»), клик по пункту
  открывает соответствующее окно;
- если качается что-то одно — нужное окно открывается сразу, без меню и без
  «угадывания» (раньше клик всегда открывал окно скачивания платформы).

Привязка закачки к окну: `platform:` → «Скачивание версии платформы 1С»,
`platform-update:` → «Обновление платформы 1С», `update:`/`chain:` → окно
«Проверка обновлений» той ИБ, для которой качается обновление/цепочка.

**Попутно исправлено на Linux.** Индикатор фоновых загрузок там не работал:
общий ViewModel-файл индикатора не подключался к Linux-сборке, подписка на
менеджер загрузок не выполнялась, и панель оставалась скрытой. Файл подключён,
подписка добавлена; клик по тексту индикатора в Avalonia заработал (раньше
текст был некликабельным).

Тесты: `dotnet test` — **2298** passed, 0 failed; сборки Windows и Linux — без
ошибок. Issues остаются открытыми — жду обратной связи.
