# Управление конфигурациями 1С — v0.3.9.276

Серия из **шести улучшений** (цикл 0.3.9.271–0.3.9.276) по обращениям и задачам проекта,
сгруппированных в шесть пакетов: окно выбора скрипта (П1), учётные записи ИТС (П2),
поле «Конфигурация» в окне правки базы (П3), URL публикации и локаль (П4), режим
«Отбор запущенных» (П5), горизонтальный скролл списка баз (П6). Каждое улучшение
реализовано на **обеих платформах** (Windows/WPF и Linux/Avalonia) с юнит-тестами.

## Изменения

### П1. Окно выбора скрипта (0.3.9.271)

1. **0.3.9.271 — [#308](https://github.com/sivatorov/ConfigurationManagement/issues/308)**
   — при открытии окна фокус ставится на список сценариев и выбирается первый пункт
   (через `Loaded`/`Opened`, после отображения окна); клавиша **Enter** выполняет
   выбранный сценарий — равнозначно кнопке «Выполнить» и двойному клику, событие
   помечается обработанным.

### П2. Учётные записи ИТС (0.3.9.272)

2. **0.3.9.272 — [#333](https://github.com/sivatorov/ConfigurationManagement/issues/333)**
   — список обновляется сразу после удаления записи (раньше — только после перезапуска,
   добавлен `Reload()`); двойной клик по строке таблицы открывает окно правки
   (WPF — `MouseDoubleClick`, Avalonia — `DoubleTapped`); кнопка «Задать основным» стала
   видимой — вместо иконки-звезды с ToolTip текстовая кнопка «иконка + текст»
   единообразно на обеих платформах; для записей без имени в списках выбора учёток
   подставляется локализованный плейсхолдер «Без имени».

### П3. Поле «Конфигурация» в окне правки базы (0.3.9.273)

3. **0.3.9.273 — [#338](https://github.com/sivatorov/ConfigurationManagement/issues/338)**
   — поле заменено с TextBox на редактируемый выпадающий список: наполняется
   уникальными значениями конфигураций всех баз списка (отсев пустых, distinct без
   учёта регистра, сортировка), при этом допустим и ручной ввод произвольного значения —
   сохраняется текст из поля (`Text`), а не выбранный пункт, поэтому введённое вручную
   значение не теряется (регресс #164 исключён); автодополнение отключено, чтобы не
   конфликтовать с вводом.

### П4. URL публикации и локаль (0.3.9.274)

4. **0.3.9.274 — [#332](https://github.com/sivatorov/ConfigurationManagement/issues/332)**
   — при добавлении/правке базы URL публикации пропускается через
   `OneCLauncher.StripWebLocaleSegment`: завершающий сегмент локали вида `/ru_RU/`,
   `/en_US/` тихо отрезается (как уже делал фикс 0.3.9.234 для «Перейти по ссылке»);
   единая точка правки `ConnectionSettingsViewModel.ApplyTo` покрывает обе платформы.

### П5. Режим «Отбор запущенных» (0.3.9.275)

5. **0.3.9.275 — [#339](https://github.com/sivatorov/ConfigurationManagement/issues/339)**
   — кнопка-переключатель в панели вкладок списка баз: при включении показываются только
   базы с активным процессом 1С, флаги актуализируются мгновенно (`RefreshRunningFlags`),
   без ожидания 10-секундного опроса; двойной клик и Enter в режиме отбора не запускают
   базу повторно, а активируют уже открытое окно 1С (Windows: поиск процесса по командной
   строке → видимое окно → `SW_RESTORE` + `SetForegroundWindow`, новый хелпер
   `OneCWindowActivator`; Linux: метод-заглушка — активация чужих окон на X11 требует
   wmctrl/xdotool, ограничение описано в issue); добавлен настраиваемый хоткей
   «Отбор запущенных» в окне «Настройки → Клавиши».

### П6. Горизонтальный скролл списка баз (0.3.9.276)

6. **0.3.9.276 — [#309](https://github.com/sivatorov/ConfigurationManagement/issues/309)**
   — горизонтальная прокрутка списка баз, восьмая попытка (Windows/WPF): когда сумма
   ширин колонок превышает ширину вьюпорта, ItemsPanel дерева динамически переключается
   с `VirtualizingStackPanel` на обычный `StackPanel` — тот даёт честный
   `ExtentWidth = DesiredSize`, и полоса прокрутки гарантированно достигает последней
   колонки; виртуализация отключается только на время отображения полосы и возвращается
   при нормальной ширине; расширен инструментальный лог `CM_COLUMNS` — выводятся total,
   sumActualHeader, content, presenterMin, viewport, extent. Linux/Avalonia не затронута —
   проблема на ней не воспроизводится.
