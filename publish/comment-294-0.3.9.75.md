Исправлено в версии **0.3.9.75** (Windows/WPF и Linux/Avalonia).

Все четыре замечания были справедливы. Вот что изменилось.

**1. Пароль больше не «одноразовый» — появилась смена пароля.**
В меню «Утилиты», сразу после «Блокировки приложения», появился пункт
«Сменить пароль блокировки». Окно запрашивает текущий пароль, затем новый
и его повтор; новый пароль действует сразу и будет запрошен при следующей
разблокировке. Если пароль ещё не задан, окно работает в режиме установки.
Сбрасывать пароль правкой файла настроек больше не нужно.

**2. Блокировка переживает закрытие из трея и перезапуск.**
Раньше состояние блокировки жило только в памяти сеанса: закрыли приложение
из трея, запустили заново — блокировки нет. Теперь состояние сохраняется в
настройках (флаг `AppLockActive` в settings.json) в момент включения блокировки
и снимается только после ввода верного пароля. Если приложение было закрыто
заблокированным, при следующем запуске окно открывается с оверлеем
«Приложение заблокировано» и окном ввода пароля.

**3. После включения блокировки пароль сразу не запрашивается.**
По пункту 3 из вашего сообщения — согласен, запрос пароля сразу после
включения блокировки был бессмысленным: пользователь ведь только что сам
её включил. Теперь при включении блокировки окно просто сворачивается в трей
(если путь возврата недоступен — сворачивается в панель задач) и не мешает
работать.

**4. Пароль спрашивается при попытке открыть приложение.**
Пока блокировка активна, любой путь к окну — клик по значку в трее, пункт
«Открыть», активация второй копией приложения, запуск после перезапуска —
показывает окно ввода пароля. Если окно ввода закрыть без верного пароля
(крестик, «Отмена», Esc), приложение сворачивается обратно. Снять блокировку
можно только вводом верного пароля; на время блокировки горячие клавиши окна
отключены.

**Как проверить:**

1. Установите версию **0.3.9.75** (файлы на странице релиза
   [v0.3.9.78](https://github.com/sivatorov/ConfigurationManagement/releases/tag/v0.3.9.78)).
2. Меню «Утилиты» → «Блокировка приложения»: задайте пароль — приложение
   свернётся в трей без запроса пароля.
3. Закройте приложение из трея и запустите заново — окно откроется
   заблокированным, с запросом пароля.
4. Введите неверный пароль — предупреждение; закройте окно ввода — приложение
   свернётся обратно в трей; верный пароль — блокировка снята.
5. Меню «Утилиты» → «Сменить пароль блокировки» — текущий, новый, повтор:
   следующий вход только по новому паролю.
