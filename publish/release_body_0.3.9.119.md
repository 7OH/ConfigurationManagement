# Управление конфигурациями 1С — v0.3.9.119

Серия из **двух изменений** (0.3.9.118–0.3.9.119) — обработка двух issues автора:
перенос кнопки копирования в окне создания информационной базы (#306) и пять
замечаний по функциональности «Сценарии запуска скриптов» (#308). Каждое изменение
реализовано на **обеих платформах** (Windows/WPF и Linux/Avalonia).

## Изменения

1. **Кнопка копирования перенесена к полю «Имя базы данных»** (0.3.9.118, #306) —
   кнопка-иконка (ContentCopy) больше не стоит у поля «Наименование»: теперь она
   находится у поля «Имя базы данных» и копирует значение из «Имя базы на сервере»
   (RefBox) в «Имя базы данных» (DbNameBox). Поле «Наименование» не затрагивается.
   Пустое значение Ref приёмник не затирает (поведение сохранено).

2. **Сценарии запуска скриптов: 5 замечаний автора (#308)** — финальная доводка
   функции «Сценарии»:
   - **Двойной клик вставляет только токен** (а) — раньше в поле параметров
     попадала строка «%name% — имя базы» целиком; теперь список содержит объекты
     `ScriptTokenHint` с шаблоном отображения «%токен% — описание», а вставка
     выполняет только сам токен.
   - **Резолвер принимает все ключи подстановок + пароль** (б) — добавлены
     `%connection.password%`/`%password%` и динамический проход рефлексией по
     публичным свойствам `ConnectionSettings`/`Infobase` (кэшированные списки):
     любые текущие и будущие свойства моделей подхватываются автоматически
     (ключи `connection.<имя>` и плоские `<имя>` в нижнем регистре); явные ключи
     перезаписывают динамические, поведение неизвестного ключа не изменилось.
   - **Комбобокс «База для примера подстановок» показывает имя базы** (в) — на
     Linux/Avalonia задан `DisplayMemberPath = nameof(Infobase.Name)` (раньше
     отображалось имя типа), на Windows/WPF выставляется `SelectedIndex = 0`,
     чтобы комбобокс и превью показывали одну базу.
   - **Редактирование сценария больше не создаёт копию** (г) — окна редактирования
     (WPF и Avalonia) сохраняют переданный сценарий и применяют поля к нему же:
     `Id` сохраняется, `ScriptScenarioStore.Save` перезаписывает тот же файл —
     дубли в списке не появляются.
   - **Свойство «Скрывать окно скрипта»** (д) — `ScriptScenario.HideWindow` (по
     умолчанию `true`), чекбокс в окне редактирования (обе платформы),
     `ExternalCommandRunner` получил публичный `CreateProcessStartInfo(command,
     createNoWindow = true)` и параметр `createNoWindow` в `RunAsync`/`RunDetached`;
     запуск сценариев использует `createNoWindow: !scenario.HideWindow` — при
     снятой галке на Windows появляется консольное окно `cmd`. На Linux `/bin/sh`
     выполняется без терминала, видимое окно зависит от окружения.
