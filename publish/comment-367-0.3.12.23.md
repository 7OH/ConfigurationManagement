Исправлено в версии **0.3.12.23**:

- Для задания «Проверка наличия обновления для конфигурации» добавлена опция «Уведомлять об отсутствии обновлений».
- Уведомление «обновлений нет» теперь показывается только при включённой опции; при выключенной опции задание завершается без уведомления, если обновления отсутствуют.
