# Управление конфигурациями 1С — v0.3.9.233

Серия из **двенадцати новых функций** (цикл 0.3.9.161–0.3.9.233) по собственной дорожной
карте проекта: просмотр журнала регистрации (.lgd), задания по расписанию через
планировщики ОС, импорт баз из кластера 1С, регламентные задания кластера в мониторе
серверов, уведомления в Telegram и по email, массовая замена в строках подключения,
пользовательские действия контекстного меню, проверка резервных копий тестовым
восстановлением, автообновление платформы 1С, расширенный интерфейс командной строки,
импорт баз из CSV и диагностика сети до сервера 1С. Каждая функция реализована на
**обеих платформах** (Windows/WPF и Linux/Avalonia) с юнит-тестами.

## Изменения

1. **Просмотр журнала регистрации ИБ (0.3.9.161–0.3.9.166)** — чтение файлов журнала
   регистрации 1С: SQLite `.lgd` (платформы 8.3.5–8.3.21, строго read-only, с
   интроспекцией схемы — имена колонок 1С менялись между версиями платформы) и
   последовательный формат `.lgf`+`.lgp`; расшифровка кодов пользователей, компьютеров,
   приложений, событий и метаданных через справочные таблицы (при отсутствии — «сырые»
   коды); фильтры, экспорт и окно просмотра на обеих платформах; открытие журнала
   файловой базы из списка или напрямую из файла.

2. **Задания по расписанию вне приложения (0.3.9.167–0.3.9.171)** — выполнение заданий
   через планировщики ОС, когда приложение не запущено: чистый маппинг расписания
   «HH:mm + дни недели» в строку `crontab` Linux и XML-определение Windows Task Scheduler
   (`schtasks /Create /XML`, управляемый блок `# BEGIN/END ConfigurationManagement`,
   чужие записи пользователя не трогаются); статус задания разбирается из XML-вывода
   `schtasks /Query` без зависимости от локали ОС; настройка «Выполнять задания даже без
   запущенного приложения», headless-команда `--run-task` и синхронизация заданий при
   изменении/удалении.

3. **Импорт информационных баз из кластера 1С (0.3.9.172–0.3.9.175)** — подключение к
   ragent/RAS через `rac` (`infobase summary list --cluster=<uuid>` + `cluster list`/
   `cluster info`), чеклист баз с пометкой дубликатов по строке подключения и файловых ИБ
   кластера (не импортируются), маппинг в подключение приложения (хост кластера из
   `hostName`, порт кластера из `cluster list`, `Ref` — имя ИБ); сводка перед
   подтверждением, автоматическое создание групп по имени кластера; пароль администратора
   живёт только в памяти окна и на диск не сохраняется.

4. **Регламентные задания кластера 1С (0.3.9.176–0.3.9.179)** — новая вкладка
   «Регламентные задания» в мониторе серверов (CTRL+ALT+S): RAS-слой
   (`job list --cluster=<uuid>`, позиционный парсер вывода, управление состоянием
   `job pause/resume/disable/enable`); таблица заданий (имя, база-владелец, метод,
   cron-расписание, состояние с цветом, следующий/последний запуск, предопределённость),
   фильтр по базе, кнопки «Приостановить/Возобновить» с подтверждением, окно «Детали»,
   автообновление 5 с; задания видны только администратору кластера, старые rac без
   job-команд показывают понятную ошибку.

5. **Уведомления в Telegram и по email (0.3.9.180–0.3.9.186)** — мультиканальный
   диспетчер уведомлений: системные (трей/notify-send) + Telegram (бот) + email (SMTP на
   встроенных `System.Net.Sockets`/`SslStream`, без новых NuGet-зависимостей); вкладка
   «Уведомления» в окне настроек (адреса каналов, PasswordBox, выбор событий, проверка
   подключения), фильтр событий `NotifyOn*`, вид события (Success/Error/Info); секреты
   (токен бота, пароль SMTP) шифруются и не попадают в журнал.

6. **Массовая замена в строке подключения баз (0.3.9.187–0.3.9.192)** — окно «Заменить
   в строках подключения…» на обеих платформах: поля Server/Port/Ref/FilePath/WebUrl/Any,
   режимы точное совпадение/префикс/подстрока/regex, регистронезависимость; предпросмотр
   «база | поле | было → станет» без мутаций, подтверждение с числом баз, JSON-бэкап
   списка перед применением, одноуровневый откат «Отменить последнюю замену» из окна и из
   «Утилит»; приватные базы не затрагиваются.

7. **Пользовательские действия контекстного меню (0.3.9.193–0.3.9.199)** — произвольные
   команды через системный shell (Авто/cmd/PowerShell/sh) с подстановкой токенов
   `{ИмяБазы}`, `{СтрокаПодключения}`, `{Сервер}`, `{Пользователь}`, `{Пароль}` и др. и
   экранированием для shell; области применения (база/группа/обе, мультивыделение),
   таймаут по умолчанию 30 с, горячие клавиши с валидацией конфликтов, подтверждение;
   окна списка/редактора с живым превью, хранилище `custom_actions.json`, история запусков
   с маскированием пароля.

8. **Проверка резервных копий тестовым восстановлением (0.3.9.200–0.3.9.207)** — проверка
   копий на читаемость: быстрая структура / полное тестовое восстановление через
   `ibcmd`/`1cv8`, единый JSON-кэш результатов `backup_validation_cache.json` с
   актуальностью по отпечатку файла, проверка вручную и по расписанию; в «Центре
   обслуживания» — колонка «Проверка копий», учёт повреждённых копий в фильтре «Только
   проблемы» и HTML-отчёте.

9. **Автообновление платформы 1С (0.3.9.208–0.3.9.216)** — окно обновления (Ctrl+F9):
   каталог версий с портала `releases.1c.ru` (парсер таблиц, файлы дистрибутивов
   zip/deb/rpm с размерами), сопоставление с установленными и совместимость с базами,
   многопоточная загрузка с докачкой, тихая установка на Windows (UAC, проверка подписи)
   и sudo-команды для Linux, предупреждения перед установкой (занятые процессы, права,
   свободное место, подпись), удаление старых версий с исключением используемых и
   запущенных.

10. **Расширенный интерфейс командной строки (0.3.9.217–0.3.9.223)** — единый контракт
    вывода (`ok`/`command`/`data`/`error.code`, при `--json` — валидный JSON независимо от
    локализации); headless-вход: команды выполняются до создания GUI и работают из
    планировщика ОС (cron/schtasks) без DISPLAY; команды `--run`, `--list` (детали баз),
    `--help`, `--export` (CSV как в UI-экспорте / JSON) и `--run-task`; единые коды
    возврата 0/1/2/3 с документированной миграцией.

11. **Импорт баз из CSV (0.3.9.224–0.3.9.228)** — разбор CSV (строгий UTF-8, построчная
    обработка ошибок, маппинг заголовков ru/en), восстановление типа базы из строки
    подключения, окно импорта с предпросмотром и отчётом о пропусках по причинам, команда
    «Импорт из CSV…» в «Утилитах»; круговой сценарий «экспорт → импорт» на случайных
    полях.

12. **Диагностика сети до сервера 1С (0.3.9.229–0.3.9.233)** — окно «Диагностика
    подключения» (из контекстного меню базы и из монитора серверов): резолв DNS, ICMP-пинг
    (на Linux без прав raw-socket помечается «не проверено»), TCP-проверка портов
    1540/1541/1545 параллельно с измерением RTT, выводы-подсказки по матрице правил;
    опциональная быстрая TCP-проверка порта кластера в проверке доступности баз
    (флажок настройки, по умолчанию выключена — quick-fail «недоступно», финальное слово
    за COM).
