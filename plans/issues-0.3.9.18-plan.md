## 2. Issue #267 — «Странная колонка» (новый, без комментариев)

### 2.1. Суть проблемы (тело issue, автор 7OH)
Окно «Актуальные релизы»:
1. Есть **пустая колонка**, назначение которой не понятно.
2. Колонка «Ссылка на каталог релизов» — заголовок целиком не влазит (предложение — сократить до «Ссылка»).
3. **Текст ссылки при выделении строки не видно** — серый остаётся серым.
4. Текст ссылки не влазит (обрезается); в конце указано — возможно делать ссылкой последнюю графу, а полную
   либо копировать, либо открывать.
5. **При копировании** строки ссылка не копируется (копируется всё, кроме ссылки), хотя интуитивно хочется
   копировать значение ячейки. Либо должна быть кнопка открытия.

### 2.2. Текущее состояние кода (WPF)
В [`ActualReleasesWindow.xaml`](Configuration%20Management/Views/ActualReleasesWindow.xaml:166) колонки:
- `Name` (текстовая, `ElementStyle=CenteredCellText`);
- `LatestVersion` (шаблонная, TextBlock);
- `Status` (текстовая);
- **`Url`** (шаблонная колонка, строка 195): `<TextBlock Text="{Binding Url}" ... Foreground="{DynamicResource TextSecondaryBrush}" TextTrimming="CharacterEllipsis"/>` — серый текст, обрезается, без обработки клика/выделения;
- колонка **`ProgressBar`** (ширина 130, строки 205–241) — прогресс/статус загрузки;
- две колонки-кнопки (Refresh — 44px, Download — 44px).

Кандидат на «пустую колонку» — колонка прогресса (`Width="130"`), которая при простое выглядит пустой,
либо статусная колонка. **Требуется уточнить у автора/сопоставить со скриншотом, какая именно колонка пустая.**

Заголовок `Updates.Url` («Ссылка на каталог релизов») в шаблоне заголовка обрезается.

### 2.3. Предлагаемые правки
**WPF** — [`ActualReleasesWindow.xaml`](Configuration%20Management/Views/ActualReleasesWindow.xaml:195) и
[`ActualReleasesWindow.xaml.cs`](Configuration%20Management/Views/ActualReleasesWindow.xaml.cs):
1. **Пустая колонка** — идентифицировать, что это (вероятно колонка прогресса). Если это она — либо
   скрывать прогресс-колонку/лейбл, когда не идёт проверка/скачивание (уже `Collapsed` для `ProgressBar`,
   но лейбл пустой), либо сделать явную колонку статуса. Согласовать с автором.
2. **Заголовок** — сократить локализованный заголовок колонки `Url` до «Ссылка» (ресурс локализации),
   либо разрешить перенос/подпись заголовка.
3. **Видимость ссылки при выделении** — убрать жёсткий `Foreground="{DynamicResource TextSecondaryBrush}"`
   или переключать цвет на `TextPrimaryBrush`/контрастный при `IsSelected` (DataTrigger в стиле TextBlock),
   чтобы выделенный текст был читаем.
4. **Кликабельность/копирование** — сделать текст ссылки кликабельным:
   - по клику открывать URL в браузере (команда/обработчик);
   - либо показывать кнопку/меню «Открыть / Копировать»;
   - согласовать желаемое поведение (открыть vs копировать vs кнопка) с автором.
5. **Копирование ячейки** — обеспечить, чтобы при копировании строки/ячейки копировалось значение ссылки
   (`Url`), а не весь текст строки (при необходимости — явное копирование значения ячейки по Ctrl+C или
   контекстное меню).

**Avalonia** — [`ActualReleasesWindow.Avalonia.cs`](Configuration%20Management/Views/ActualReleasesWindow.Avalonia.cs):
паритет по пп. 1–5 для ручного `Grid`/`TextBlock`.

### 2.4. Требуемое уточнение
Перед кодом уточнить у автора (комментарий в issue) **какая колонка считается «пустой»** и **желаемое
поведение ссылки** (открывать/копировать/кнопка). Это условие — blocker для задачи (иначе возможны
неверные правки).

### 2.5. Критерии готовности
- Нет непонятной «пустой» колонки (либо её назначение очевидно/подписано).
- Заголовок колонки ссылки помещается / сокращён.
- Текст ссылки читаем при выделении строки.
- Ссылка кликабельна (открывается в браузере) или копируется значение ячейки.
- Паритет WPF/Avalonia.

## 3. Issue #266 — «Добавить отступы слева» (новый, без комментариев)

### 3.1. Суть проблемы (тело issue, автор 7OH)
В окнах «Типовые конфигурации» и «Актуальные релизы» в первую колонку (а лучше во все текстовые) добавить
небольшой отступ слева и справа, чтобы буквы не начинались прямо от границы и не уходили впритык.

### 3.2. Текущее состояние кода (WPF)
В [`ConfigTypesEditWindow.xaml`](Configuration%20Management/Views/ConfigTypesEditWindow.xaml:138) и
[`ActualReleasesWindow.xaml`](Configuration%20Management/Views/ActualReleasesWindow.xaml:138) у

### 3.3. Предлагаемые правки
**WPF** — [`ConfigTypesEditWindow.xaml`](Configuration%20Management/Views/ConfigTypesEditWindow.xaml:138) и
[`ActualReleasesWindow.xaml`](Configuration%20Management/Views/ActualReleasesWindow.xaml:138):

**Avalonia** — [`ConfigTypesEditWindow.Avalonia.cs`](Configuration%20Management/Views/ConfigTypesEditWindow.Avalonia.cs)
и [`ActualReleasesWindow.Avalonia.cs`](Configuration%20Management/Views/ActualReleasesWindow.Avalonia.cs):
добавить `Padding`/`Margin` в ячейки/`TextBlock` ручной сетки (паритет с WPF).

### 3.4. Критерии готовности
- В обоих окнах текст текстовых колонок имеет равномерный отступ слева и справа.
- Центрирование ячеек (issue #265/#264) и шаблонные колонки не сломаны.
- Паритет WPF/Avalonia.
