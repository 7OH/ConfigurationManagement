> Источник: статья Infostart «[StartManager 1.4 — Развитие альтернативного стартера](https://infostart.ru/1c/tools/274485/)».
> Цель: сопоставить функционал StartManager 1.4 с открытым проектом
> «Управление конфигурациями 1С» и внедрить отсутствующие функции поэтапно.
>
> Каждый этап выполняется в **отдельной новой задаче**. Крупные этапы
> (1, 2, 4) сначала декомпозируются через **режим Архитектора**, затем
> реализуются в **режиме Code**. Остальные этапы выполняются напрямую
> в режиме Code.

## 3. Поэтапный план внедрения

Каждый этап = отдельная новая задача. Для этапов с пометкой
«декомпозиция в Архитекторе» сначала создаётся задача в режиме Архитектора
(декомпозиция → todo → ревью плана), затем запускается реализация в Code.

### Этап 1 — Проверка обновлений конфигураций и «Актуальные релизы» *(декомпозиция в Архитекторе)*
Функции №21, №22.
- Список типовых конфигураций (предопределённый набор + редактирование).
- Формирование web-адреса обновлений по правилу 1С
  (`downloads.1c.ru/ipp/.../Configs/<Конфигурация>/<Ред>/<Подред>/`),
  ручная корректировка ссылки и проверка.
- Проверка обновлений для выбранной ИБ (клавиша **F9**), окно проверки,
  подсветка нового релиза, кнопка загрузки.
- Окно «Актуальные релизы» (**ALT+F9**): список отслеживаемых конфигураций,
  пакетная проверка.
- Настройка связи ИБ ↔ конфигурация и определение релиза автоматически
  (кнопка «Определить версию», чтение из структуры конфигурации).

### Этап 2 — Сценарии резервирования и восстановление *(декомпозиция в Архитекторе)*
Функции №16, №18.
- Модель «Сценарий резервирования»: наименование, шаблон имени файла/архива,
  до 3 каталогов назначения, формат (DT/CF/ZIP/RAR), префикс базы, пользователи.
- Хранение сценариев в отдельных файлах, неограниченное количество.
- Выполнение сценария (**SHIFT+CTRL+F5**).
- Форма «Список выгрузок» (**SHIFT+CTRL+F7**) и загрузка данных обратно
  (в т.ч. без открытия конфигуратора — `/RestoreIB`).
- ZIP через `System.IO.Compression`; RAR — через внешнюю утилиту (winrar)
  либо как опция, зависящую от наличия архиватора.

### Этап 3 — Блокировка сеансов файловой ИБ + временная блокировка StartManager
Функции №19, №20.
- Установка/снятие блокировки сеансов файловой ИБ без открытия
  «1С:Предприятия» (**CTRL+ALT+L**): время начала (по умолчанию +5 мин),
  длительность (по умолчанию 30 мин), текст сообщения с параметрами
  `{ДатаНач}`/`{ДатаКон}`, шаблоны «Технические работы» и «Обновление ИБ».
- Временная блокировка самого приложения паролем (на время отсутствия).

### Этап 4 — Механизм закладок *(декомпозиция в Архитекторе)*
Из журнала изменений 1.4.0.144/145/153.
- Колонка закладок в списке баз, до 9 закладок (номера 1..9), иконка номера.
- Установка: `Ctrl+щелчок`, `Ctrl+Shift+P`, `Ctrl+Shift+[1..9]`, меню `Ctrl+B`.
- Перемещение: `Ctrl+[1..9]`, меню `Ctrl+B`; разворачивание свёрнутой группы.
- Очистка: `Ctrl+щелчок`, все — `Ctrl+Alt+X`, удаление конкретной.
- Запуск по закладке: `Alt+<номер>` — Предприятие, `Ctrl+Alt+<номер>` —
  Конфигуратор, `Alt+E` — все базы с закладками.
- Сохранение/восстановление закладок между сеансами.

### Этап 5 — Интеграция с проводником Windows
Функция №12.
- Регистрация ассоциации `.1CD` и контекстного меню проводника:
  «Зарегистрировать в списке баз» / «Запустить 1С:Предприятие» /
  «Запустить Конфигуратор».
- Включение через Настройки → Сервис → Интеграция → «Интегрировать с проводником».

### Этап 6 — chdbfl.exe и консоль администрирования серверов
Функция №29 + функция из журнала изменений.
- Быстрый запуск `chdbfl.exe` с подстановкой пути к файловой ИБ.
- Запуск консоли администрирования серверов 1С для клиент-серверных баз.

### Этап 7 — Внешняя обработка при запуске + действие по двойному щелчку
Функции №25, №28.
- Поле «Внешняя обработка» в свойствах ИБ; запуск обработки при открытии
  в режиме «1С:Предприятие».
- Настраиваемое действие по двойному щелчку: глобально и индивидуально для ИБ.

### Этап 8 — Автозапуск при старте Windows + копия экрана
Функции №31, №30.
- Автозапуск при начале работы Windows (ключ реестра `HKCU\...\Run`
  или планировщик).
- Сохранение копии экрана в файл по предопределённому сочетанию клавиш
  (настраиваемый каталог сохранения).

### Этап 9 — Интеграция Snegopat для 8.2/8.3
Функция №8.
- Отдельное подключение Snegopat для платформ «8.2» и «8.3».
- Возможность установки переменной окружения `PATH_1C` перед запуском.

### Этап 10 — Режимы функциональности + конфиг 1CLaunch.cfg + портативный режим
Функция №1 + функции из журнала изменений.
- Режимы: Пользователь / Специалист / Разработчик; ограничение доступа
  в системное меню для режима «Пользователь».
- Параметры запуска из `1CLaunch.cfg`: `configpath` (asp/usp/sp), `configdir`,
  `appmode`, `selectmodeoff`; приоритет командной строки над файлом.
- Портативный режим / установка на сменный носитель (перенос настроек).

### Этап 11 — Поддержка 8.1/8.2 + альтернативные списки ИБ
Функции №2, №4.
- Отображение ИБ для платформ 8.1/8.2/8.3/8.4 одновременно и по отдельности
  (фильтр по платформе).
- Альтернативные файлы списков ИБ отдельно для каждой платформы.

### Этап 12 — Раздельные учётные данные
Функция №7.
- Отдельные имя пользователя/пароль для режимов «Конфигуратор»
  и «1С:Предприятие», а также для Хранилища конфигурации.

### Этап 13 — Колонка «Дата изменений» + автосохранение состояния списка
Функции №3, №15 (дополнение).
- Колонка «Дата изменений» файла ИБ (уже есть `LastWriteTime` в
  [`FoundFileBase.cs`](../Configuration%20Management/Models/FoundFileBase.cs:22) — добавить в колонки списка).
- Сохранение/восстановление состояния списка (раскрытые группы) с
  настраиваемой периодичностью автосохранения.

## 4. Порядок запуска задач

1. Выбрать этап.
2. Создать **новую задачу** (инструмент делегирования):
   - для этапов 1/2/4 — в режиме **Architect** (декомпозиция → план → ревью),
     затем переключение в **Code**;
   - для остальных — сразу в режиме **Code**.
3. После завершения этапа обновить todo-список дорожной карты и перейти к следующему.
