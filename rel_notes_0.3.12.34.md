# 0.3.12.34

## Добавлено

### issue #365 — «Обозреватель метаданных»: выбор версии платформы

- В панель источника окна добавлено поле **«Платформа:»** — редактируемый ComboBox со
  списком установленных версий платформы 1С (обе платформы: WPF и Avalonia).
- Значение подставляется автоматически:
  - при открытии окна и при выборе базы — платформа этой базы (добавляется в список,
    если не установлена);
  - при переключении на «Файл .cf» — максимальная установленная версия;
  - пользователь может изменить версию вручную (в т.ч. произвольным текстом).
- Выбранная версия используется при распаковке файла .cf (`DumpFromCfAsync`) вместо
  прежнего неявного выбора — это чинит ошибку создания базы из .cf на неподходящей
  (более поздней) платформе.

## Тесты

Добавлено 5 тестов (`MetadataExplorerViewModelTests`): версия базы в списке и выбор при
открытии, отсутствие установленных (fallback на версию базы), смена базы, переключение
на .cf (максимальная установленная), ручной ввод версии, передаваемой в `DumpFromCfAsync`.

## Проверка

- Полный прогон тестов: 2567/2567 зелёных.
- Ручной чек-лист: открытие обозревателя с предвыбранной базой (поле показывает платформу
  базы), смена базы (подставляется её платформа), переключение на «Файл .cf» (максимальная
  установленная), ручной ввод произвольной версии, загрузка конфигурации из .cf с выбранной
  платформой.
